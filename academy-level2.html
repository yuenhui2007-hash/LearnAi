Module 1: Dashboard & Chat Interface

Dashboard Overview

The Zetrix AI Dashboard is your central hub. It provides:

  • Quick Access: Recent conversations, favourite prompts, and pinned documents
  • Usage Analytics: Track queries, tokens used, and time saved
  • Team Workspace: Shared prompts and knowledge bases for departments
  • Settings: Configure AI behaviour, memory, and integrations

Chat Best Practices

  • Thread context: AI remembers the current conversation thread
  • Regenerate: If an answer is poor, ask AI to try again with tweaks
  • Follow-up questions: Drill deeper: "Explain step 3 in more detail"
  • System prompts: Set persona at thread start: "You are a senior financial analyst"

🎯 Interactive Walkthrough

Task: Start a new chat and use this opening prompt:

"You are an expert marketing strategist. I need to create a 30-day social media campaign for a new fitness app targeting professionals aged 25-40. Structure your response as: objectives, platforms, content calendar, KPIs."

Module 2: File Uploads & Document Analysis

Supported File Types

  • PDFs: Extract text, summarise, answer questions
  • Excel/CSV: Analyse data, create charts, find anomalies
  • Word docs: Review, rewrite, translate
  • Images: OCR text extraction, description, analysis
  • Code files: Review, debug, explain

Document Analysis Techniques

  • Summarise: "Summarise this 50-page report in 5 bullet points"
  • Extract: "List all action items and deadlines from this meeting minutes"
  • Compare: "Compare contract v1 and v2 — highlight all changes"
  • Q&A: "Based on this policy document, what is the leave entitlement?"

Upload a company policy PDF. Ask AI three questions about it. Take a screenshot of the conversation.

Module 3: AI Memory

How AI Memory Works

Zetrix AI Memory allows the system to remember preferences, facts, and context across sessions:

  • User Profile: Name, role, department, writing style preferences
  • Project Context: Active projects, deadlines, stakeholders
  • Knowledge Base: Company SOPs, brand guidelines, product info
  • Conversation History: Reference past discussions

Memory Commands

  • "Remember that I work in the Finance department and prefer concise bullet points"
  • "Add to my knowledge base: Our company colours are navy blue and gold"
  • "What did we discuss about the Q3 budget last week?"
  • "Forget my previous preference for formal tone"

Module 5: Telegram Integration

Connect your Claw AI Avatar to Telegram so users can interact with it via the Telegram app.

Step 1: Create a Telegram Bot

  1. Open Telegram and search for @BotFather (verify it is the official account).
  2. Send the command: /newbot
  3. Enter your bot name when prompted.
  4. Choose a unique username ending with bot (e.g., zetrix_ai_bot).
  5. Copy the Bot Token provided by BotFather. You will need this later.

Step 2: Configure the Bot in Claw AI Avatar

In the Claw AI Avatar / OpenClaw configuration, enable the Telegram channel and add the bot token:

{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "YOUR_BOT_TOKEN",
      "dmPolicy": "pairing",
      "groups": {
        "*": {
          "requireMention": true
        }
      }
    }
  }
}

The default pairing policy allows only approved users to interact with the bot.

Step 3: Start the Gateway

After saving the configuration, start (or restart) the Claw / OpenClaw gateway so the Telegram configuration is loaded.

Step 4: Pair Your Telegram Account

  1. Search for your new bot in Telegram and start a conversation by sending /start.
  2. If pairing mode is enabled, the bot generates a pairing code.
  3. Approve the pairing from the gateway using:
    openclaw pairing list telegram
    openclaw pairing approve telegram <PAIRING_CODE>
  4. Pairing codes typically expire after one hour.

Step 5: Test the Bot

Send a simple message such as Hello or What can you do?. If everything is configured correctly, Claw AI Avatar should respond through Telegram.

Step 6: (Optional) Add the Bot to a Group

  1. Add the bot to the group.
  2. Keep requireMention: true if you want the bot to respond only when mentioned.
  3. To let the bot see all group messages, disable BotFather's Privacy Mode using /setprivacy or make the bot a group administrator. After changing Privacy Mode, remove and re-add the bot for the change to take effect.
