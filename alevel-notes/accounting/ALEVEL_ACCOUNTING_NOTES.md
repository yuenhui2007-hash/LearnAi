### 1.1 The Accounting Cycle

**Overview:** The accounting cycle is the step-by-step process of recording and processing all financial transactions of a business from when the transaction occurs to its inclusion in the financial statements.

| Stage | Description | Output |
|-------|-------------|--------|
| 1. Source Documents | Evidence that a transaction has occurred | Invoice, receipt, cheque, credit note |
| 2. Books of Prime Entry | First place transactions are recorded | Sales Day Book, Purchases Day Book, Cash Book, Journal |
| 3. Ledger Accounts | Transactions posted to individual accounts | General Ledger, Sales Ledger, Purchases Ledger |
| 4. Trial Balance | List of all ledger balances | Trial Balance |
| 5. Financial Statements | Final accounts prepared | Income Statement, Statement of Financial Position |
| 6. Closing Entries | Accounts reset for next period | Balances carried down / brought down |

[DIAGRAM: Accounting Cycle Flowchart – circular diagram showing the 6 stages with arrows]

**Key Principle:** Every transaction affects at least two accounts (double-entry system).

### 1.2 Books of Prime Entry

Books of prime entry are the first books in which transactions are recorded. They are also known as **books of original entry** or **day books**.

| Book | Records | Source Document |
|------|---------|-----------------|
| Sales Day Book (SDB) | Credit sales | Sales invoices (copies) |
| Purchases Day Book (PDB) | Credit purchases | Purchases invoices |
| Sales Returns Day Book (SRDB) | Goods returned by customers | Credit notes issued |
| Purchases Returns Day Book (PRDB) | Goods returned to suppliers | Credit notes received |
| Cash Book | All cash and bank transactions | Receipts, cheque stubs, paying-in slips |
| Petty Cash Book | Small cash payments | Petty cash vouchers |
| Journal | Non-routine / infrequent transactions | Various – see below |

#### The Journal (General Journal)

Used for:
- Opening entries
- Purchases/sales of fixed assets on credit
- Correction of errors
- Transfer between accounts
- Depreciation
- Bad debts written off\n- Drawings of goods

**Journal Format:**

| Date | Details | Dr ($) | Cr ($) |
|------|---------|--------|--------|
| | Account to be debited | XX | |
| | Account to be credited | | XX |
| | *(Narrative explaining the transaction)* | | |

### 1.3 Ledger Accounts & Double Entry

#### The Accounting Equation

```
Assets = Capital + Liabilities
```

Extended:
```
Assets = Capital + (Revenue − Expenses) + Liabilities
```

#### Double Entry Rules

| Account Type | Debit (Dr) | Credit (Cr) |
|-------------|-----------|-------------|
| **Assets** | Increase | Decrease |
| **Liabilities** | Decrease | Increase |
| **Capital** | Decrease | Increase |
| **Revenue/Income** | Decrease | Increase |
| **Expenses** | Increase | Decrease |

#### T-Account Format

```
        Dr                    Account Name                  Cr
  ───────────────────────────────────────────────────────────────
  Date   Details      $     |     Date   Details           $
  ───────────────────────────────────────────────────────────────
                         |                              
```

#### Balancing Accounts

1. Total both sides
2. Insert balance on the side with the smaller total
3. Total both sides (now equal)
4. Bring balance down (b/d) on the opposite side for the next period

### 1.4 Trial Balance

**Purpose:** To check the arithmetical accuracy of ledger accounts.

**Format:**

| Account | Debit ($) | Credit ($) |
|---------|-----------|------------|
| All asset accounts | XX | |
| All expense accounts | XX | |
| All drawings | XX | |
| All liability accounts | | XX |
| All income accounts | | XX |
| All capital accounts | | XX |
| **Total** | **XXX** | **XXX** |

**Limitations:** A balanced trial balance does NOT prove:
- Correct accounts were used
- Transactions were not omitted
- Transactions were not duplicated
- Compensating errors exist

### 1.5 Correction of Errors

#### Types of Errors

| Error Type | Description | Does it affect TB? |
|-----------|-------------|-------------------|
| **Error of omission** | Transaction completely left out | No |
| **Error of commission** | Wrong account (same class) | No |
| **Error of principle** | Wrong class of account | No |
| **Error of original entry** | Wrong amount in both accounts | No |
| **Reversal of entries** | Dr and Cr swapped | No |
| **Compensating error** | Two errors cancel out | No |
| **Error of duplication** | Recorded twice | No |
| **Single entry** | Only one side recorded | **Yes** |

#### Suspense Account

Used when the trial balance does not balance. The difference is placed in a **suspense account** temporarily until errors are found and corrected.

**Process:**
1. Identify errors from the suspense account balance
2. Prepare journal entries to correct each error
3. Post journals to ledgers
4. Clear the suspense account

### 1.6 Bank Reconciliation Statements

**Purpose:** Reconcile the difference between the **cash book** balance and the **bank statement** balance.

#### Common Differences

| Item | Cash Book | Bank Statement |
|------|-----------|----------------|
| Unpresented cheques | Deducted | Not yet deducted |
| Uncredited deposits | Added | Not yet added |
| Bank charges | Not yet deducted | Deducted |
| Standing orders / DD | Not yet deducted | Deducted |
| Direct credits | Not yet added | Added |
| Dishonoured cheques | Not yet deducted | Deducted |
| Errors | May need correction | May need correction |

#### Steps:
1. Update the cash book for items on the bank statement but not in cash book
2. Prepare reconciliation statement starting from updated cash book
3. Adjust for timing differences (unpresented cheques, uncredited deposits)
4. Reconciled balance should equal bank statement balance

#### Reconciling Control Accounts

Differences may arise from:
- Different amounts posted (transposition errors)
- Omitted entries
- Incorrectly cast day books

### 1.8 Capital vs Revenue Expenditure and Receipts

| Capital Expenditure | Revenue Expenditure |
|--------------------|---------------------|
| Acquiring/upgrading long-term assets | Day-to-day operating costs |
| Benefits multiple accounting periods | Benefits current period only |
| Appears in Statement of Financial Position | Appears in Income Statement |
| Examples: machinery, buildings, vehicles | Examples: wages, rent, utilities |

| Capital Receipts | Revenue Receipts |
|-----------------|------------------|
| From sale of non-current assets | From sale of goods/services |
| Loans raised | Income from investments |
| Owner's capital introduced | Commission received |

**Capitalised costs:** Costs that can be added to asset value:
- Delivery costs
- Installation costs
- Legal fees for property purchase
- Testing costs before use

**Revenue costs that may be confused:**
- Repairs and maintenance (revenue)
- Improvement/upgrade (capital)
- Replacement of parts (revenue unless extends useful life)

### 2.3 Limited Company Accounts

#### Share Capital

| Type | Description |
|------|-------------|
| **Authorised / Nominal / Registered Capital** | Maximum shares the company is allowed to issue |
| **Issued Capital** | Shares actually issued to shareholders |
| **Called-up Capital** | Amount the company has asked shareholders to pay |
| **Paid-up Capital** | Amount actually paid by shareholders |
| **Uncalled Capital** | Amount not yet called for |

#### Types of Shares

| Ordinary Shares | Preference Shares |
|----------------|------------------|
| Owners of the company | Preference over ordinary for dividends |
| Voting rights | Usually no voting rights |
| Variable dividends | Fixed dividend rate |
| Last in liquidation | Priority in liquidation |

| Reserve | Source | Usage |
|---------|--------|-------|

| **General Reserve** | Transfer from retained earnings | Reinforcement of capital; future investment |
| **Retained Earnings** | Accumulated profits less dividends | Distributable as dividends |

#### Debentures

- Long-term loan capital
- Fixed rate of interest (paid regardless of profit)
- Secured against company assets (usually)
- No voting rights
- Risk of default if company fails

### 2.5 Incomplete Records

#### Calculating Missing Figures

**When sales figure is missing:**

Use the receivables control account:
```
Opening receivables + Credit sales − Sales returns − Cash received − Discounts allowed − Bad debts − Dishonoured cheques = Closing receivables
```

**When purchases figure is missing:**

Use the payables control account:
```
Opening payables + Credit purchases − Purchases returns − Cash paid − Discounts received = Closing payables
```

#### Markup vs Margin

| | Formula | When Cost is Base | When Selling Price is Base |
|---|---|---|---|
| **Markup** | Profit / Cost × 100 | Yes | |
| **Margin** | Profit / Selling Price × 100 | | Yes |

**Conversion:**
- Markup 25% = Margin 20%
- Margin 20% = Markup 25%

Formula:
```
If markup = x%, then margin = x / (100 + x) × 100
If margin = y%, then markup = y / (100 − y) × 100
```

### 3.1 Financial Ratios

#### Profitability Ratios

| Ratio | Formula | What It Shows |
|-------|---------|--------------|
| **Gross Profit Margin** | (Gross Profit / Revenue) × 100 | Pricing and direct cost control |
| **Net Profit Margin** | (Net Profit / Revenue) × 100 | Overall efficiency |
| **ROCE** | (Operating Profit / Capital Employed) × 100 | Return on total capital |
| **ROE** | (Net Profit / Shareholders' Equity) × 100 | Return to shareholders |

#### Liquidity Ratios

| Ratio | Formula | Ideal | Interpretation |
|-------|---------|-------|---------------|
| **Current Ratio** | CA / CL | 1.5–2.0 | Short-term solvency |
| **Acid Test** | (CA − Inventory) / CL | 1.0+ | Immediate liquidity |

#### Efficiency Ratios

| Ratio | Formula | What It Shows |
|-------|---------|--------------|
| **Inventory Turnover** | COS / Average Inventory | Speed of stock turnover |
| **Inventory Days** | (Avg Inventory / COS) × 365 | Average holding period |
| **Receivables Days** | (Receivables / Revenue) × 365 | Average collection period |
| **Payables Days** | (Payables / COS) × 365 | Average payment period |

#### Gearing Ratios

| Ratio | Formula | Interpretation |
|-------|---------|---------------|
| **Gearing** | (NCL / Capital Employed) × 100 | Financial risk level |
| **Interest Cover** | Operating Profit / Interest | Ability to pay interest |

#### Investor Ratios

| Ratio | Formula | What It Shows |
|-------|---------|--------------|
| **EPS** | PAT / Number of ordinary shares | Earnings per share |
| **P/E Ratio** | Market Price / EPS | Market confidence |
| **Dividend Yield** | (DPS / Market Price) × 100 | Income return |
| **Dividend Cover** | EPS / DPS | Dividend sustainability |

### 3.5 Limitations of Financial Statements

1. **Historical cost** – assets recorded at original cost, not current value
2. **Not forward-looking** – past performance may not predict future
3. **Subject to accounting policies** – different policies produce different results
4. **Does not include non-financial factors** – staff morale, brand reputation, customer loyalty
5. **Can be manipulated** – window dressing, creative accounting
6. **Time lag** – published months after year-end
7. **Inflation effects** – values distorted in inflationary periods

### 4.1 Cost Classification

#### By Element

| Cost | Description |
|------|-------------|
| **Materials** | Raw materials, components, packaging |
| **Labour** | Wages, salaries, bonuses, employer's NI |
| **Overheads** | Indirect costs: rent, utilities, depreciation |

#### By Traceability

| Direct Costs | Indirect Costs (Overheads) |
|-------------|---------------------------|
| Can be traced to specific cost unit | Cannot be traced; must be apportioned |
| Direct materials, direct labour | Factory rent, supervisor salary, depreciation |

#### By Behaviour

| Fixed | Variable | Semi-Variable |
|-------|----------|---------------|
| Constant regardless of output | Changes proportionally with output | Part fixed, part variable |
| Rent, insurance, salaries | Raw materials, direct labour, sales commission | Utilities, phone bills |

#### By Function

| Production | Administration | Selling & Distribution | Finance |
|-----------|---------------|----------------------|---------|
| Factory costs | Office costs | Marketing, delivery | Interest, bank charges |

#### By Controllability

| Controllable | Uncontrollable |
|-------------|---------------|
| Manager can influence | Outside manager's influence |
| Direct materials (purchasing manager) | Rent (set by landlord) |

---

### 4.2 Costing Methods

#### Job Costing

- Costs accumulated for each individual job/order
- Used in: printing, construction, bespoke furniture, professional services
- Each job has its own cost card

#### Batch Costing

- Similar to job costing but for batch of identical items
- Unit cost = Total batch cost / Number of units in batch
- Used in: bakeries, clothing manufacturing, pharmaceutical production

#### Process Costing

- Costs accumulated by process/department
- Used in: oil refining, chemical production, food processing

**Key Features:**
- Equivalent units for work-in-progress
- Normal loss: Expected loss; cost borne by good units
- Abnormal loss/gain: Unexpected; charged to Income Statement

**Process Costing Steps:**
1. Prepare statement of equivalent units
2. Calculate cost per equivalent unit
3. Apportion costs between completed units and closing WIP
4. Account for normal and abnormal losses

#### Service Costing

- Costing for service industries
- Cost units may be intangible (e.g., passenger-km, bed-nights, consulting hours)

---

### 4.3 Overhead Absorption

#### Three-Stage Process

**1. Allocation:**
- Directly assign whole cost items to cost centres
- Example: Factory rent allocated to Production Dept A

**2. Apportionment:**
- Divide shared costs between cost centres on fair basis
- Common bases:

| Overhead | Basis of Apportionment |
|----------|----------------------|
| Rent, rates, heating | Floor area |
| Power, machine depreciation | Machine value or machine hours |
| Canteen costs | Number of employees |
| Depreciation of buildings | Floor area |
| Supervision | Number of employees |
| Lighting | Floor area or number of light points |

**3. Absorption (Recovery):**
- Charge overheads to cost units using overhead absorption rate (OAR)

```
OAR = Budgeted Overheads / Budgeted Activity Level
```

Activity levels:
- Units produced
- Direct labour hours
- Machine hours
- Direct labour cost
- Prime cost

**Under-absorption and Over-absorption:**

| | Under-absorbed | Over-absorbed |
|---|---|---|
| **Cause** | Actual overheads > absorbed | Actual overheads < absorbed |
| **Meaning** | Not enough overhead charged | Too much overhead charged |
| **Adjustment** | Add to cost of sales | Deduct from cost of sales |

---

### 4.4 Marginal Costing

#### Key Concepts

| Term | Formula | Meaning |
|------|---------|---------|
| **Contribution** | Selling Price − Variable Cost | Amount towards fixed costs and profit |
| **Break-even output** | Fixed Costs / Contribution per unit | Output where total cost = total revenue |
| **Break-even revenue** | Fixed Costs / Contribution to Sales Ratio | Revenue where total cost = total revenue |
| **Margin of Safety** | (Actual Sales − Break-even Sales) / Actual Sales × 100 | Cushion before losses occur |
| **Contribution to Sales (C/S) Ratio** | Contribution / Selling Price × 100 | Also called PV ratio |

#### Break-even Chart

- X-axis: Output / Sales
- Y-axis: Cost and Revenue
- Fixed cost line: Horizontal
- Total cost line: Starts at fixed cost, slopes upward
- Revenue line: Starts at origin, slopes upward
- Break-even point: Where total cost = total revenue

#### Profit/Volume (P/V) Graph

- X-axis: Output / Sales
- Y-axis: Profit / Loss
- At zero sales: Loss = Fixed costs
- Break-even: Profit = 0
- Slopes upward at contribution rate

#### Marginal vs Absorption Costing

| | Marginal Costing | Absorption Costing |
|---|---|---|
| **Fixed overheads** | Period cost (expensed immediately) | Product cost (included in inventory valuation) |
| **Inventory valuation** | Variable cost only | Full production cost |
| **Profit difference** | Lower profit when inventory increases | Higher profit when inventory increases |
| **Use** | Decision-making, break-even analysis | External reporting (required by IAS 2) |

### 4.6 Standard Costing

#### Setting Standards

| Type | How Set |
|------|---------|
| **Ideal** | Perfect conditions, no waste | Theoretical maximum |
| **Attainable** | Efficient but realistic | Normal conditions with normal waste |
| **Current** | Based on current actual | Reflects current inefficiencies |

#### Variance Formulas

**Materials:**

| Variance | Formula |
|----------|---------|
| **Material Price Variance** | (Standard Price − Actual Price) × Actual Quantity |
| **Material Usage Variance** | (Standard Quantity − Actual Quantity) × Standard Price |

**Labour:**

| Variance | Formula |
|----------|---------|
| **Labour Rate Variance** | (Standard Rate − Actual Rate) × Actual Hours |
| **Labour Efficiency Variance** | (Standard Hours − Actual Hours) × Standard Rate |

**Variable Overheads:**

| Variance | Formula |
|----------|---------|
| **Variable Overhead Expenditure Variance** | (Standard Rate − Actual Rate) × Actual Hours |
| **Variable Overhead Efficiency Variance** | (Standard Hours − Actual Hours) × Standard Rate |

**Fixed Overheads (Absorption Costing):**

| Variance | Formula |
|----------|---------|
| **Fixed Overhead Expenditure Variance** | Budgeted Fixed Overheads − Actual Fixed Overheads |
| **Fixed Overhead Volume Variance** | (Actual Production − Budgeted Production) × Standard Fixed Overhead Rate |

#### Variance Summary

```
Total Material Cost Variance
  ├── Material Price Variance: (SP − AP) × AQ
  └── Material Usage Variance: (SQ − AQ) × SP

Total Labour Cost Variance
  ├── Labour Rate Variance: (SR − AR) × AH
  └── Labour Efficiency Variance: (SH − AH) × SR

Total Variable Overhead Variance
  ├── Variable Overhead Expenditure Variance: (SR − AR) × AH
  └── Variable Overhead Efficiency Variance: (SH − AH) × SR
```

**Favourable (F) vs Adverse (A):**

| Variance | Favourable | Adverse |
|----------|-----------|---------|
| Price/Rate | Paid less than standard | Paid more than standard |
| Usage/Efficiency | Used less than standard | Used more than standard |
| Expenditure | Spent less than budget | Spent more than budget |
| Volume | Produced more than budget | Produced less than budget |

**Reconciling Budgeted and Actual Profit:**

```
Budgeted Profit                                           $ XX
Add: Favourable variances / Less: Adverse variances       $ XX
                                                             ────
Actual Profit                                             $ XX
```

#### Causes of Variances

| Variance | Possible Causes |
|----------|----------------|
| Material Price (F) | Bulk discounts, price falls, better purchasing |
| Material Price (A) | Price rises, poor purchasing, urgent orders |
| Material Usage (F) | Better quality materials, less waste, skilled workers |
| Material Usage (A) | Poor quality materials, waste, theft, unskilled workers |
| Labour Rate (F) | Use of trainees, wage freeze, cheaper labour |
| Labour Rate (A) | Overtime, wage rises, use of higher-grade labour |
| Labour Efficiency (F) | Motivated workers, better training, better machinery |
| Labour Efficiency (A) | Poor training, machine breakdown, low morale |

### 4.7 Investment Appraisal

#### Payback Period

```
Payback = Years before full recovery + (Unrecovered cost at start of year / Cash flow during the year)
```

| Advantages | Disadvantages |
|------------|---------------|
| Simple to understand and calculate | Ignores cash flows after payback |
| Favours liquidity | Ignores time value of money |
| Useful in uncertain environments | Subjective target period |

#### Accounting Rate of Return (ARR)

```
ARR = (Average Annual Profit / Average Investment) × 100

Average Investment = (Initial Cost + Scrap Value) / 2
```

| Advantages | Disadvantages |
|------------|---------------|
| Uses familiar profit figures | Ignores time value of money |
| Easy to calculate | Uses accounting profit not cash flow |
| Easy to compare with target | Subjective target rate |

#### Net Present Value (NPV)

```
NPV = Σ [Cash Flow_t / (1 + r)^t]
```

| Advantages | Disadvantages |
|------------|---------------|
| Considers time value of money | Requires accurate forecasts |
| Absolute measure of value added | Sensitive to discount rate |
| Considers all cash flows | Ignores non-financial factors |

**Discount Factors:**

| Year | 5% | 10% | 15% | 20% |
|------|----|-----|-----|-----|
| 1 | 0.952 | 0.909 | 0.870 | 0.833 |
| 2 | 0.907 | 0.826 | 0.756 | 0.694 |
| 3 | 0.864 | 0.751 | 0.658 | 0.579 |
| 4 | 0.823 | 0.683 | 0.572 | 0.482 |
| 5 | 0.784 | 0.621 | 0.497 | 0.402 |

#### Internal Rate of Return (IRR)

The discount rate that makes NPV = 0.

**Interpolation formula:**
```
IRR = Lower rate + [NPV at lower rate / (NPV at lower rate − NPV at higher rate)] × (Higher rate − Lower rate)
```

| Advantages | Disadvantages |
|------------|---------------|
| Considers time value | Complex to calculate |
| Percentage is intuitive | Multiple IRRs possible |
| No need to specify rate | Reinvestment assumption unrealistic |

#### Annuities

When cash flows are equal each year:
```
NPV = Annual Cash Flow × Annuity Factor − Initial Investment
```

**Annuity Factors:**

| Years | 5% | 10% | 15% | 20% |
|-------|----|-----|-----|-----|
| 2 | 1.859 | 1.736 | 1.626 | 1.528 |
| 3 | 2.723 | 2.487 | 2.283 | 2.106 |
| 4 | 3.546 | 3.170 | 2.855 | 2.589 |
| 5 | 4.329 | 3.791 | 3.352 | 2.991 |

## WORKED EXAMPLE 2: Suspense Account & Error Correction

### Scenario
From the trial balance above, there is a $10,000 difference (debit > credit). Investigation reveals the following errors:

**Error 1:** A purchase of goods from ABC Suppliers for $6,000 was correctly entered in the purchases account but was posted to ABC Suppliers account as $600.

**Error 2:** Cash sales of $2,000 were correctly entered in the cash account but were completely omitted from the sales account.

**Error 3:** A payment of rent $3,000 was entered in the bank account as $300 and in the rent account as $3,000.

**Error 4:** Purchases returns of $500 to ABC Suppliers were entered in ABC Suppliers account but not in the purchases returns account.

---

### Error Analysis

**Error 1 — Commission (Transposition error):**
- Should be: Dr Purchases $6,000, Cr ABC Suppliers $6,000
- Actually: Dr Purchases $6,000, Cr ABC Suppliers $600
- Effect: Credit side understated by $5,400 ($6,000 − $600)
- Correction: Dr Suspense $5,400, Cr ABC Suppliers $5,400

**Error 2 — Omission:**
- Should be: Dr Cash $2,000, Cr Sales $2,000
- Actually: Dr Cash $2,000 (done), Cr Sales $0 (omitted)
- Effect: Credit side understated by $2,000
- Correction: Dr Suspense $2,000, Cr Sales $2,000

**Error 3 — Original entry error:**
- Should be: Dr Rent $3,000, Cr Bank $3,000
- Actually: Dr Rent $3,000 (correct), Cr Bank $300 (understated)
- Effect: Credit side overstated by $2,700 ($3,000 − $300)
- Correction: Dr Bank $2,700, Cr Suspense $2,700

**Error 4 — Omission:**
- Should be: Dr Purchases Returns $500, Cr ABC Suppliers $500
- Actually: Dr Purchases Returns $0 (omitted), Cr ABC Suppliers $500 (done)
- Effect: Debit side understated by $500
- Correction: Dr Purchases Returns $500, Cr Suspense $500

## WORKED EXAMPLE 8: Overhead Absorption

### Scenario
A factory has two production departments (A and B) and one service department (C).

**Overheads to be apportioned:**
- Rent and rates: $50,000
- Power: $30,000
- Depreciation on machinery: $40,000
- Supervision: $24,000
- Insurance of machinery: $10,000

**Department data:**

| | Dept A | Dept B | Dept C | Total |
|---|---|---|---|---|
| Floor area (sq m) | 2,000 | 1,500 | 500 | 4,000 |
| Machine value ($) | 200,000 | 150,000 | 50,000 | 400,000 |
| Number of employees | 40 | 30 | 10 | 80 |
| Machine hours | 10,000 | 6,000 | — | 16,000 |
| Direct labour hours | 8,000 | 4,000 | — | 12,000 |

**Service department C overheads are reapportioned to A and B in the ratio 60:40.**

**Production data:**
- Dept A: Budgeted overheads $120,000; Budgeted machine hours 10,000
- Dept B: Budgeted overheads $80,000; Budgeted direct labour hours 4,000

Job X requires:
- Dept A: 50 machine hours
- Dept B: 20 direct labour hours

---

### Step 1: Primary Apportionment

| Overhead | Basis | Dept A | Dept B | Dept C | Total |
|----------|-------|--------|--------|--------|-------|
| Rent and rates | Floor area (20:15:5) | $25,000 | $18,750 | $6,250 | $50,000 |
| Power | Machine hours (10:6:0) | $18,750 | $11,250 | $0 | $30,000 |
| Depreciation | Machine value (20:15:5) | $20,000 | $15,000 | $5,000 | $40,000 |
| Supervision | Employees (40:30:10) | $12,000 | $9,000 | $3,000 | $24,000 |
| Insurance | Machine value (20:15:5) | $5,000 | $3,750 | $1,250 | $10,000 |
| **Total after primary** | | **$80,750** | **$57,750** | **$15,500** | **$154,000** |

### Step 2: Reapportion Service Department

Service Dept C ($15,500) reapportioned 60:40 to A:B
- Dept A: $15,500 × 60% = $9,300
- Dept B: $15,500 × 40% = $6,200

| | Dept A | Dept B |
|---|---|---|
| After primary apportionment | $80,750 | $57,750 |
| Add: Service department | $9,300 | $6,200 |
| **Total production overheads** | **$90,050** | **$63,950** |

### Step 3: Calculate OAR

**Dept A (Machine Hour Rate):**
```
OAR = $90,050 / 10,000 machine hours = $9.005 per machine hour
```

**Dept B (Direct Labour Hour Rate):**
```
OAR = $63,950 / 4,000 labour hours = $15.9875 per labour hour
```

### Step 4: Calculate Overhead Absorbed by Job X

```
Dept A: 50 machine hours × $9.005 = $450.25
Dept B: 20 labour hours × $15.9875 = $319.75
Total overhead absorbed by Job X = $770.00
```

## WORKED EXAMPLE 9: Standard Costing Variances

### Scenario
Standard cost card for one unit of product:
- Direct materials: 5 kg at $4/kg = $20
- Direct labour: 2 hours at $8/hour = $16
- Variable overhead: 2 hours at $3/hour = $6
- Fixed overhead: 2 hours at $5/hour = $10
- Total standard cost = $52

Actual results for 1,000 units produced:
- Materials used: 5,200 kg at $4.20/kg
- Labour hours: 1,900 hours at $8.50/hour
- Variable overhead: $5,500
- Fixed overhead: $11,000
- Budgeted production: 1,000 units

---

### Variance Calculations

**Material Price Variance:**
= (Standard Price − Actual Price) × Actual Quantity
= ($4.00 − $4.20) × 5,200 kg
= −$0.20 × 5,200
= **$1,040 Adverse**

**Material Usage Variance:**
= (Standard Quantity − Actual Quantity) × Standard Price
= (5,000 kg − 5,200 kg) × $4.00
= −200 × $4.00
= **$800 Adverse**

**Labour Rate Variance:**
= (Standard Rate − Actual Rate) × Actual Hours
= ($8.00 − $8.50) × 1,900 hours
= −$0.50 × 1,900
= **$950 Adverse**

**Labour Efficiency Variance:**
= (Standard Hours − Actual Hours) × Standard Rate
= (2,000 hours − 1,900 hours) × $8.00
= 100 × $8.00
= **$800 Favourable**

**Variable Overhead Expenditure Variance:**
= (Standard Rate − Actual Rate) × Actual Hours
Actual rate = $5,500 / 1,900 = $2.8947
= ($3.00 − $2.8947) × 1,900
= **$200 Favourable**

**Variable Overhead Efficiency Variance:**
= (Standard Hours − Actual Hours) × Standard Rate
= (2,000 − 1,900) × $3.00
= 100 × $3.00
= **$300 Favourable**

**Fixed Overhead Expenditure Variance:**
= Budgeted Fixed Overheads − Actual Fixed Overheads
= $10,000 − $11,000
= **$1,000 Adverse**

**Fixed Overhead Volume Variance:**
= (Actual Production − Budgeted Production) × Standard Fixed Overhead Rate
= (1,000 − 1,000) × $10
= **$0**

## WORKED EXAMPLE 10: Investment Appraisal

### Scenario
A company is considering investing in a new project with the following cash flows:

| Year | Cash Flow |
|------|-----------|
| 0 | ($100,000) |
| 1 | $30,000 |
| 2 | $35,000 |
| 3 | $40,000 |
| 4 | $25,000 |
| 5 | $20,000 |

Cost of capital: 12%

---

### Payback Period

| Year | Cash Flow | Cumulative |
|------|-----------|------------|
| 1 | $30,000 | $30,000 |
| 2 | $35,000 | $65,000 |
| 3 | $40,000 | $105,000 |

Payback occurs in Year 3.

Exact payback:
```
= 2 years + ($100,000 − $65,000) / $40,000
= 2 years + $35,000 / $40,000
= 2 years + 0.875
= 2.875 years (or 2 years 10.5 months)
```

### NPV Calculation (at 12%)

| Year | Cash Flow | Discount Factor (12%) | Present Value |
|------|-----------|----------------------|---------------|
| 0 | ($100,000) | 1.000 | ($100,000) |
| 1 | $30,000 | 0.893 | $26,790 |
| 2 | $35,000 | 0.797 | $27,895 |
| 3 | $40,000 | 0.712 | $28,480 |
| 4 | $25,000 | 0.636 | $15,900 |
| 5 | $20,000 | 0.567 | $11,340 |
| **Total** | | | **$10,405** |

**NPV = $10,405 (Positive → Accept)**

### IRR Calculation

Try 18%:

| Year | Cash Flow | DF (18%) | PV |
|------|-----------|----------|-----|
| 0 | ($100,000) | 1.000 | ($100,000) |
| 1 | $30,000 | 0.847 | $25,410 |
| 2 | $35,000 | 0.718 | $25,130 |
| 3 | $40,000 | 0.609 | $24,360 |
| 4 | $25,000 | 0.516 | $12,900 |
| 5 | $20,000 | 0.437 | $8,740 |
| **Total** | | | **($3,460)** |

Interpolation:
```
IRR = 12% + [$10,405 / ($10,405 + $3,460)] × (18% − 12%)
    = 12% + ($10,405 / $13,865) × 6%
    = 12% + 0.750 × 6%
    = 12% + 4.5%
    = 16.5%
```

**IRR = 16.5% (Greater than cost of capital 12% → Accept)**

## WORKED EXAMPLE 11: Process Costing with Normal and Abnormal Loss

### Scenario
A product passes through Process 1. Input: 10,000 units at $5 per unit.

Additional costs:
- Direct labour: $20,000
- Overheads: $15,000

Normal loss: 10% of input (expected)
Actual output: 8,800 units
Scrap value of normal loss: $2 per unit
There is no closing work-in-progress.

---

### Process 1 Account

```
Process 1 Account

Units       $                    Units       $
─────────────────────────────────────────────────
Input    10,000   50,000   Normal loss   1,000    2,000
Labour            20,000   Abnormal loss   200    7,600
Overheads         15,000   Output        8,800  75,400
─────────────────────────────────────────────────
       10,000   85,000                 10,000   85,000
```

**Working:**

Normal loss = 10,000 × 10% = 1,000 units
Expected output = 10,000 − 1,000 = 9,000 units
Actual output = 8,800 units
Abnormal loss = 9,000 − 8,800 = 200 units

Cost per unit:
```
= (Total cost − Scrap value of normal loss) / Expected output
= ($85,000 − $2,000) / 9,000 units
= $83,000 / 9,000
= $9.222 per unit
```

Value of output = 8,800 × $9.222 = $81,154 (rounded to $75,400 + $7,600 + $2,000 check)

Actually, let's recalculate:
```
Total cost to account for: $85,000
Less: Scrap value of normal loss: 1,000 × $2 = $2,000
Net cost: $83,000
Expected good output: 9,000 units
Cost per unit: $83,000 / 9,000 = $9.2222

Value of normal loss: 1,000 × $2 = $2,000 (scrap value)
Value of abnormal loss: 200 × $9.2222 = $1,844
Value of output: 8,800 × $9.2222 = $79,156

Check: $2,000 + $1,844 + $79,156 = $83,000 ✓
```

# APPENDIX: EXAM TIPS & FORMULAS

## General Exam Tips

1. **Show all workings** – method marks are awarded even if final answer is wrong.
2. **Use correct formats** – present accounts in standard formats with proper headings.
3. **Label everything** – dates, currency signs, account names.
4. **Check your arithmetic** – trial balance and control accounts must balance.
5. **Time management** – don't spend too long on one question.
6. **Read the question carefully** – note what is required (prepare, calculate, explain).
7. **Use the mark allocation** – 1 mark ≈ 1 minute of work.

## Common Mistakes to Avoid

| Topic | Common Error | Correct Approach |
|-------|-------------|-----------------|
| Trial Balance | Including wrong side | Know your Dr/Cr rules |
| Suspense Account | Using it for all errors | Only for errors affecting TB agreement |
| Bank Reconciliation | Not updating cash book first | Always update cash book before reconciliation |
| Control Accounts | Including cash sales in SLCA | SLCA = credit sales only |
| Depreciation | Forgetting to adjust for disposals | Calculate depreciation up to date of disposal |
| Partnerships | Missing guarantee of profit | Check for new partner guarantees |
| Manufacturing | Including office costs | Only factory costs in manufacturing account |
| Ratios | Wrong denominator for ROCE | Capital employed = equity + NCL |
| Cash Flows | Wrong tax/dividends paid | Use SOFP movement, not income statement charge |
| Process Costing | Ignoring scrap value of normal loss | Deduct scrap value before calculating cost per unit |
| Marginal Costing | Confusing contribution and profit | Contribution = Sales − Variable Costs |
| Variance Analysis | Wrong sign for F/A | Favourable = better for profit, Adverse = worse |
| NPV | Using profit instead of cash flow | NPV uses cash flows, not accounting profit |

## Formula Quick Reference Sheet

```
GROSS PROFIT = Net Sales − Cost of Sales

OPERATING PROFIT = Gross Profit − Operating Expenses

NET PROFIT = Operating Profit − Interest − Tax

CONTRIBUTION = Selling Price − Variable Cost

BREAK-EVEN OUTPUT = Fixed Costs / Contribution per unit

MARGIN OF SAFETY = (Actual Sales − Break-even Sales) / Actual Sales × 100

C/S RATIO = Contribution / Sales × 100

ROCE = Operating Profit / Capital Employed × 100

CAPITAL EMPLOYED = Shareholders' Equity + Non-Current Liabilities

GEARING = (Non-Current Liabilities / Capital Employed) × 100

INTEREST COVER = Operating Profit / Interest Payable

CURRENT RATIO = Current Assets / Current Liabilities

ACID TEST = (Current Assets − Inventory) / Current Liabilities

INVENTORY DAYS = (Average Inventory / Cost of Sales) × 365

RECEIVABLES DAYS = (Trade Receivables / Credit Sales) × 365

PAYABLES DAYS = (Trade Payables / Credit Purchases) × 365

EPS = Profit after Tax / Number of Ordinary Shares

P/E RATIO = Market Price per Share / EPS

NPV = Σ [Cash Flow_t / (1 + r)^t]

OAR = Budgeted Overheads / Budgeted Activity Level

EQUIVALENT UNITS = Units Completed + (Closing WIP × % Completion)
```
