Straight Line Graphs

IGCSE Content

1. Gradient & Intercept

y = mx + c \quad \text{where } m = \text{gradient, } c = \text{y-intercept}

2. Finding the Equation of a Line

m = \frac{y₂ - y₁}{x₂ - x₁} \quad y - y₁ = m(x - x₁)

3. Parallel & Perpendicular Lines

\text{Parallel: } m₁ = m₂ \quad \text{Perpendicular: } m₁ \times m₂ = -1

4. Midpoint & Distance

M = \left(\frac{x₁+x₂}{2}, \frac{y₁+y₂}{2}\right) \quad d = \sqrt{(x₂-x₁)² + (y₂-y₁)²}

AS Level Content

1. Equations in Different Forms

y = mx + c \quad ax + by + c = 0 \quad \frac{x}{a} + \frac{y}{b} = 1

2. Distance from Point to Line

d = \frac{|ax₀ + by₀ + c|}{\sqrt{a² + b²}}

3. Intersection of Line and Curve

Set the equations equal to form a quadratic. Use discriminant to determine number of intersections.

A2 Level Content

1. Parametric Equations of Lines

x = x₀ + at, \quad y = y₀ + bt

2. Transformations

  • y = f(x) + a → translation by (0, a)
  • y = f(x + a) → translation by (-a, 0)
  • y = af(x) → stretch parallel to y-axis, scale factor a

Last-Minute Summary

  • Gradient: Δy/Δx. Positive → uphill, negative → downhill.
  • Equation: y - y₁ = m(x - x₁) or y = mx + c.
  • Parallel: same gradient.
  • Perpendicular: m₁ × m₂ = -1.
  • Midpoint: average the coordinates.
  • Distance: Pythagoras on coordinate differences.
  • Point to line: use formula with absolute value.
  • Line meets curve: set equal → quadratic → discriminant.
