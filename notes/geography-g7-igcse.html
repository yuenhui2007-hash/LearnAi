Vectors in Geography

Geography G7

📘 IGCSE Content

1.1 Vector Basics

A vector has both magnitude and direction. Scalars have magnitude only.

Notation: **a**, a⃗, or AB⃗ (vector from A to B).

A vector in component form: **v** = (x, y) in 2D or (x, y, z) in 3D.

1.2 Vector Operations

Addition: (a, b) + (c, d) = (a+c, b+d) Subtraction: (a, b) − (c, d) = (a−c, b−d) Scalar multiplication: k(a, b) = (ka, kb) Magnitude: |**v**| = √(x² + y²) or √(x² + y² + z²)

1.3 Position Vectors

If O is the origin, the position vector of point P is OP⃗.

The vector from A to B is: AB⃗ = OB⃗ − OA⃗ = **b** − **a**

1.4 Worked Example — Position Vectors

Problem: A = (2, 3), B = (5, 7). Find vector AB⃗ and its magnitude.

Solution:

AB⃗ = (5−2, 7−3) = (3, 4)

|AB⃗| = √(3² + 4²) = √25 = 5

1.5 Unit Vectors

A unit vector has magnitude 1. The unit vector in direction of **v** is:

**v̂** = **v** / |**v**|

Standard unit vectors: **i** = (1,0,0), **j** = (0,1,0), **k** = (0,0,1)

1.6 Section Formula (IGCSE Extended)

Point P dividing AB in ratio m:n has position vector:

**p** = (n**a** + m**b**) / (m + n)

For midpoint: **p** = (**a** + **b**) / 2

📗 AS Level Content

2.1 Scalar (Dot) Product

**a** · **b** = |**a**| |**b**| cos θ = a₁b₁ + a₂b₂ + a₃b₃

Properties:

  • Commutative: **a** · **b** = **b** · **a**
  • **a** · **a** = |**a**|²
  • If **a** ⊥ **b**, then **a** · **b** = 0

2.2 Finding Angles Between Vectors

cos θ = (**a** · **b**) / (|**a**| |**b**|)

Worked Example: Find angle between **a** = (1, 2, 2) and **b** = (3, 0, 4).

**a** · **b** = 3 + 0 + 8 = 11

|**a**| = √(1+4+4) = 3, |**b**| = √(9+0+16) = 5

cos θ = 11/15, so θ = cos⁻¹(11/15) ≈ 42.8°

2.3 Vector Equation of a Line

**r** = **a** + λ**d**

where **a** is a point on the line, **d** is the direction vector, and λ is a scalar parameter.

Cartesian form: (x − a₁)/d₁ = (y − a₂)/d₂ = (z − a₃)/d₃

2.4 Finding Line Intersections

Set the parametric equations equal and solve for parameters. If consistent: lines intersect. If inconsistent: lines are skew (in 3D) or parallel.

2.5 Shortest Distance from Point to Line

For line **r** = **a** + λ**d** and point P with position vector **p**:

Distance = |(**p** − **a**) × **d**| / |**d**|

📙 A2 Level Content

3.1 Vector (Cross) Product

**a** × **b** = |**a**| |**b**| sin θ **n̂** where **n̂** is unit vector perpendicular to both **a** and **b** (right-hand rule).

In components:

**a** × **b** = (a₂b₃ − a₃b₂, a₃b₁ − a₁b₃, a₁b₂ − a₂b₁)

Properties:

  • Anti-commutative: **a** × **b** = −(**b** × **a**)
  • **a** × **a** = **0**
  • |**a** × **b**| = area of parallelogram with sides **a** and **b**

3.2 Scalar Triple Product

[**a**, **b**, **c**] = **a** · (**b** × **c**) = det[**a** **b** **c**]

This gives the volume of the parallelepiped with edges **a**, **b**, **c**.

If [**a**, **b**, **c**] = 0, the vectors are coplanar.

3.3 Vector Equation of a Plane

**r** · **n** = d (where **n** is normal vector) or **r** = **a** + λ**b** + μ**c** (parametric form)

Cartesian form: ax + by + cz = d, where (a,b,c) = **n**

3.4 Distance from Point to Plane

Distance = |**n** · **p** − d| / |**n**| = |ax₀ + by₀ + cz₀ − d| / √(a²+b²+c²)

3.5 Line-Plane Intersection

Substitute line equation **r** = **a** + λ**d** into plane equation **r** · **n** = d.

Solve for λ. If **d** · **n** = 0: line is parallel to plane (no intersection or line lies in plane).

3.6 Vector Geometry Proofs

Example: Prove that the medians of a triangle are concurrent (centroid divides each median in ratio 2:1).

Proof: Let vertices have position vectors **a**, **b**, **c**.

Midpoint of BC: **m** = (**b** + **c**)/2

Point on median from A dividing it 2:1: (**a** + 2**m**)/3 = (**a** + **b** + **c**)/3

By symmetry, this same point lies on all three medians. ∎

📐 Worked Example

Question: Find the interior angle of a regular decagon.

Solution:
n = 10
Interior angle = (n − 2) × 180° / n
= (10 − 2) × 180° / 10 = 8 × 18° = 144°
Answer: 144°
Confusing interior and exterior angles. Exterior angles of ANY polygon always sum to 360°.
For regular polygons: interior + exterior = 180°. Use this to check your answers.

⚡ Quick Recall

  • Interior angle sum = (n − 2) × 180°
  • Exterior angle sum = 360°
  • Regular polygon interior = (n−2)×180°/n
  • Pythagoras: a² + b² = c²
