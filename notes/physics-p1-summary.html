IGCSE AS Level

Physical Quantities & Units

9702 (A-Level) · 0625 (IGCSE)

Last-Minute Revision Summary

  • SI base units: kg, m, s, A, K, mol, cd -- know all seven and their definitions
  • Derived units are combinations of base units; use dimensional analysis to verify equations
  • Principle of homogeneity: both sides of a physical equation must have identical base units
  • Scalars have magnitude only (distance, speed, mass, energy); vectors have magnitude and direction (displacement, velocity, force, momentum)
  • Distance is not equal to displacement; speed is not equal to velocity; always account for direction with vectors
  • Uncertainty: analogue = +/- half smallest division; digital = +/- 1 in last digit
  • Percentage uncertainty = (absolute uncertainty / measured value) x 100%
  • For multiplication/division: add % uncertainties; for addition/subtraction: add absolute uncertainties
  • Vernier calipers read to 0.01 mm; micrometer reads to 0.01 mm; always check for zero error
  • Resolve vectors: Vx = V cos theta, Vy = V sin theta; on inclined planes: parallel = mg sin theta, perpendicular = mg cos theta

Key Formulas

v = u + at
s = ut + 0.5at^2
v^2 = u^2 + 2as
R = rho L/A
F = ma

Common Mistakes to Avoid

  • Confusing mass (base quantity, kg) with weight (derived, N = kg m s^-2)
  • Using the wrong trigonometric function when resolving on inclined planes -- parallel = sin, perpendicular = cos
  • Forgetting that repeating measurements only reduces random errors, not systematic errors
  • Writing solidus notation (m/s^2) instead of index notation (m s^-2) for base units

Quick Exam Tips

  • Always include units in every calculation step -- method marks depend on correct unit handling
  • Write base units using index notation (kg m s^-2) not solidus (kg m/s^2) in dimensional analysis
  • When asked for 'base units', never include derived names like N, J, or W -- expand fully
  • For vector problems, always draw a labelled diagram showing vectors and angles
  • Define your positive direction before solving; stick to it consistently
  • Round uncertainties to 1 significant figure and match the measured value to that precision
  • Read the question carefully: does it ask for magnitude only, or magnitude AND direction?
  • When combining percentage uncertainties for multiplication/division, add them -- do not average
