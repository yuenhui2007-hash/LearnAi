A2 Level

Particle Physics

9702 (A-Level) · 0625 (IGCSE)

Detailed Notes

1. Fundamental Particles

All matter is composed of fundamental particles that are not made of smaller constituents. There are two main families:

  • Quarks: Six types (flavours): up (u), down (d), strange (s), charm (c), top (t), bottom (b). Quarks experience the strong nuclear force and have fractional charges.
  • Leptons: Six types: electron (e⁻), muon (μ⁻), tau (τ⁻), and their associated neutrinos (νₑ, ν_μ, ν_τ). Leptons do not experience the strong nuclear force.

📖 Key Definition

Quark: A fundamental particle that experiences the strong nuclear force and has fractional electric charge.

Lepton: A fundamental particle that does not experience the strong nuclear force.

Antiquarks have opposite signs for all quantum numbers: charge, baryon number, and strangeness. For example, an anti-up quark (ū) has charge -⅔e and baryon number -⅓.

3. Hadrons and Leptons

  • Hadrons: Particles made of quarks. They experience the strong nuclear force.
    • Baryons: Made of three quarks (qqq). Examples: proton (uud), neutron (udd), Λ⁰ (uds).
    • Mesons: Made of a quark and an antiquark (qq̄). Examples: π⁺ (ud̄), π⁻ (dū), K⁺ (us̄).
  • Leptons: Fundamental particles not made of quarks. Examples: electron, muon, neutrinos.

📝 Worked Example — Quark Composition

Question: Determine the quark composition of: (a) a neutron, (b) a π⁺ meson, (c) an antiproton.

Solution:

(a) Neutron (charge 0, baryon number +1): udd → (+⅔ − ⅓ − ⅓) = 0 ✓

(b) π⁺ (charge +1, baryon number 0): ud̄ → (+⅔ + ⅓) = +1 ✓, B = ⅓ − ⅓ = 0 ✓

(c) Antiproton (charge -1, baryon number -1): ūūđ → (-⅔ − ⅔ + ⅓) = -1 ✓, B = -⅓ − ⅓ − ⅓ = -1 ✓

4. Conservation Laws

In all particle interactions, the following quantities are conserved:

  • Charge (Q): Total charge before = total charge after.
  • Baryon number (B): Total baryon number before = total after. Quarks have B = +⅓; antiquarks B = -⅓.
  • Lepton number (L): Total lepton number before = total after. Leptons have L = +1; antileptons L = -1.
Strangeness is conserved in strong and electromagnetic interactions but can change by 0 or ±1 in weak interactions. This is why strange particles are produced in pairs (strong interaction) but decay slowly via the weak interaction.

5. Particle Exchange and Forces

Forces are mediated by exchange particles (gauge bosons):

📝 Worked Example — Conservation Check

Question: Determine whether the decay π⁺ → μ⁺ + ν_μ is possible by checking conservation laws.

Solution:

π⁺ = ud̄; μ⁺ = antimuon (L_μ = -1); ν_μ = muon neutrino (L_μ = +1)

Charge: +1 → +1 + 0 ✓

Baryon number: 0 → 0 + 0 ✓

Lepton number: 0 → -1 + 1 = 0 ✓

Conservation satisfied — decay is allowed.

⚠️ Common Misconception

Students often confuse baryons and mesons. Remember: baryons have three quarks (B = +1), mesons have one quark and one antiquark (B = 0). Both are hadrons (made of quarks). Leptons are not hadrons — they are fundamental particles with no quark structure.

🎯 Exam-Style Question

Question: (a) State the quark composition of a proton and a neutron. (b) Write the quark equation for β⁻ decay of a neutron. (c) State which fundamental force is responsible for β⁻ decay. [4 marks]

Mark Scheme

• (a) Proton = uud; Neutron = udd (1 mark — both correct)

• (b) d → u + e⁻ + ν̄_e (1 mark)

• (c) Weak nuclear force (1 mark)

Accept W⁻ boson as exchange particle for additional clarity.

🎯 Exam-Style Question

Question: The following interaction is proposed: p + π⁻ → K⁰ + Λ⁰. Given the quark compositions (p = uud, π⁻ = dū, K⁰ = ds̄, Λ⁰ = uds), determine whether this interaction is possible. [3 marks]

Mark Scheme

• Initial quarks: uud + dū = uu d d ū (1 mark)

• Final quarks: ds̄ + uds = u d d s s̄ (1 mark)

• Strangeness not conserved (-1 ≠ -1? Check: initial S = 0, final S = -1 + 0 = -1). Actually S: K⁰ = -1, Λ⁰ = -1 → total -2? Wait, K⁰ = ds̄ has S = +1, Λ⁰ = uds has S = -1 → total S = 0. Initial S = 0. Allowed by strong interaction. (1 mark for correct conclusion with reasoning)

Last-Minute Summary

  • Quarks: u(+⅔e), d(-⅓e), s(-⅓e), c(+⅔e), t(+⅔e), b(-⅓e); Baryon number = +⅓ each
  • Antiquarks have opposite charge, baryon number, and strangeness
  • Hadrons = made of quarks (baryons = 3q, mesons = q+q̄); Leptons = fundamental
  • Conserved in all interactions: charge Q, baryon number B, lepton number L
  • Strangeness conserved in strong/EM, can change by ±1 in weak
  • Exchange particles: EM = photon, Strong = gluon, Weak = W⁺/W⁻/Z⁰
  • Proton = uud; Neutron = udd; π⁺ = ud̄; π⁻ = dū

Exam Tips

  • Always check all three conservation laws (Q, B, L) for particle interactions.
  • Remember quark charges: up-type (u, c, t) = +⅔e; down-type (d, s, b) = -⅓e.
  • Baryons have B = +1; mesons have B = 0. Antiparticles have opposite quantum numbers.
  • β⁻ decay involves d → u + e⁻ + ν̄_e (weak force, mediated by W⁻).
  • β⁺ decay involves u → d + e⁺ + ν_e (weak force, mediated by W⁺).
  • Strange particles are produced in pairs (strong interaction) but decay singly (weak interaction).
