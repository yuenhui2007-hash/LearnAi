AS Level Content

The Multi-Store Model of Memory (Atkinson & Shiffrin, 1968)

Sensory Memory → Attention → Short-Term Memory (STM) → Rehearsal → Long-Term Memory (LTM)

Sensory Memory:
- Iconic (visual): lasts ~0.5 seconds
- Echoic (auditory): lasts ~3–4 seconds
- Capacity: very large
- Decay: rapid unless attended to

Short-Term Memory (STM / Working Memory):
- Capacity: 7±2 items (Miller, 1956)
- Duration: ~18–30 seconds without rehearsal
- Encoding: mainly acoustic
- Can be extended by chunking

Long-Term Memory (LTM):
- Capacity: unlimited
- Duration: potentially permanent
- Encoding: mainly semantic

Types of Long-Term Memory

  • Episodic: Personal experiences and events ("I remember my 10th birthday")
  • Semantic: Facts and general knowledge ("Paris is the capital of France")
  • Procedural: Skills and habits (riding a bike, typing)

Working Memory Model (Baddeley & Hitch, 1974)

Central Executive:
- Controls attention; coordinates slave systems
- Limited capacity

Phonological Loop:
- Phonological store (inner ear): holds speech-based info briefly
- Articulatory control process (inner voice): rehearses and refreshes

Visuospatial Sketchpad:
- Visual and spatial information
- Inner eye for visual; spatial for movement/location

Episodic Buffer (added 2000):
- Integrates information from different sources

Forgetting: Decay and Interference

  • Trace Decay Theory: Memory traces fade over time if not used. Supports: STM duration studies. Weaknesses: doesn't explain why some memories last; difficult to separate from interference.
  • Interference Theory: Other memories disrupt retrieval.
    • Proactive interference: OLD memories disrupt NEW learning
    • Retroactive interference: NEW learning disrupts OLD memories

Key Study: Loftus & Palmer (1974) — Eyewitness Testimony

  • Showed participants a film of a car accident
  • Asked: "How fast were the cars going when they ___ each other?"
  • Verbs used: smashed, collided, bumped, hit, contacted
  • "Smashed" produced highest speed estimates and false memory of broken glass
  • Conclusion: Leading questions can distort memory — post-event information interferes with original memory

A2 Level Content

reconstructive Memory

  • Memory is not like a video recording — it is reconstructed each time we recall
  • Bartlett (1932): "War of the Ghosts" — participants changed unfamiliar details to fit their cultural schemas
  • Schemas: Mental frameworks that organise knowledge — influence what we notice, encode, and recall

Factors Affecting Eyewitness Testimony

  • Anxiety/stress: Moderate arousal improves memory; extreme stress impairs it (Yerkes-Dodson Law)
  • Weapon focus: Attention drawn to weapon, reducing memory of perpetrator
  • Age: Children and elderly may be more suggestible
  • Leading questions: Post-event information alters memory (Loftus)
  • Cross-race effect: Better recognition of own-race faces

Memory Improvement Strategies

  • Mnemonics: Acronyms, method of loci, peg-word system
  • Context-dependent memory: Recall better in same environment as learning
  • State-dependent memory: Recall better in same mood/physiological state
  • Organisation: Chunking, hierarchies, mind maps

Last-Minute Summary

  • Multi-Store Model: Sensory → STM (7±2, ~20s, acoustic) → LTM (unlimited, semantic)
  • Working Memory Model: Central Executive + Phonological Loop + Visuospatial Sketchpad + Episodic Buffer
  • LTM types: Episodic (events), Semantic (facts), Procedural (skills)
  • Decay theory: memories fade over time
  • Interference: Proactive (old→new), Retroactive (new→old)
  • Loftus & Palmer: leading questions distort eyewitness memory
  • Reconstructive memory: Bartlett — schemas shape recall
  • Eyewitness factors: anxiety, weapon focus, age, leading questions, cross-race effect
  • Improve memory: mnemonics, context-dependence, state-dependence, organisation
