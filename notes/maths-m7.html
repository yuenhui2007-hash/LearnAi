Differentiation from First Principles

Differentiation finds the rate of change of a function. The derivative f'(x) gives the gradient of the curve y = f(x) at any point.

f'(x) = limh→0 f(x+h) − f(x)h
Worked Example — First Principles

Differentiate f(x) = x² from first principles.

f(x+h) = (x+h)² = x² + 2xh + h²

f(x+h) − f(x)h = 2xh + h²h = 2x + h

As h → 0: f'(x) = 2x

Rules of Differentiation

Product Rule

If y = uv, then dydx = udvdx + vdudx

Quotient Rule

If y = uv, then dydx = vdudx − udvdxv²

Chain Rule

If y = f(g(x)), then dydx = dydu × dudx
Worked Example — Product Rule

Differentiate y = x² sin x.

u = x², v = sin x

dy/dx = x² cos x + 2x sin x

Worked Example — Chain Rule

Differentiate y = (3x² + 1)⁴.

Let u = 3x² + 1, y = u⁴

dy/dx = 4u³ × 6x = 24x(3x² + 1)³

Worked Example — Quotient Rule

Differentiate y = x²x + 1.

dy/dx = (x+1)(2x) − x²(1)(x+1)² = x² + 2x(x+1)² = x(x+2)(x+1)²

Applications of Differentiation

Increasing and Decreasing Functions

  • f'(x) > 0 → f is increasing
  • f'(x) < 0 → f is decreasing
  • f'(x) = 0 → stationary point

Types of Stationary Points

TypeFirst Derivative TestSecond Derivative Test
Maximumf' changes from + to −f''(x) < 0
Minimumf' changes from − to +f''(x) > 0
Point of inflexionf' does not change signf''(x) = 0 (and changes sign)
Worked Example

Find and classify stationary points of y = x³ − 3x² + 4.

dy/dx = 3x² − 6x = 3x(x − 2) = 0 → x = 0 or x = 2

d²y/dx² = 6x − 6

At x = 0: f'' = −6 < 0 → Maximum at (0, 4)

At x = 2: f'' = 6 > 0 → Minimum at (2, 0)

Connected Rates of Change

dydt = dydx × dxdt
Worked Example

The radius of a sphere increases at 0.5 cm/s. Find the rate of increase of volume when r = 4 cm.

V = 43πr³. dV/dr = 4πr² = 64π when r = 4.

dV/dt = 64π × 0.5 = 32π cm³/s

Exam-Style Question

Question: A curve has equation y = x³ + ax² + bx + c. The curve has a stationary point at (1, 5) and passes through (0, 3). Find a, b, and c. [6]

Solution: y(0) = 3 → c = 3 (B1). y(1) = 5 → 1 + a + b + 3 = 5 → a + b = 1 (M1). dy/dx = 3x² + 2ax + b. At x = 1: 3 + 2a + b = 0 (M1). Solving: a = −4, b = 5 (A1, A1, A1)

📝 Quick Summary

  • d/dx(xⁿ) = nxⁿ⁻¹
  • Product rule: d(uv)/dx = u dv/dx + v du/dx
  • Quotient rule: d(u/v)/dx = (v du/dx − u dv/dx)/v²
  • Chain rule: dy/dx = dy/du × du/dx
  • Stationary points: f'(x) = 0; max if f'' < 0, min if f'' > 0

💡 Exam Tips

  • Always simplify before differentiating if possible.
  • When using the product or quotient rule, identify u and v clearly.
  • For stationary points, always find the y-coordinate as well as the x-coordinate.
  • Use the second derivative test when possible — it is faster than testing intervals.
  • In connected rates problems, identify which rate is given and which is required.
