📘 Subject Context

Computer Systems & Hardware is a fundamental topic in IGCSE ICT. Understanding both the theory and practical applications of information and communication technology is essential for the modern world and the examination.

IGCSE ICT tests theoretical knowledge, practical skills, and the ability to apply ICT to solve problems. Paper 1 (Theory) tests knowledge and understanding; Paper 2 (Practical) tests hands-on skills in word processing, spreadsheets, databases, and presentations.

Detailed Notes

1. Computer Systems

  • Hardware: CPU, memory, storage, I/O devices
  • CPU: ALU, CU, registers

⚠️ Common Mistakes to Avoid

  • Using "hacking" as a generic term — be specific about the type of threat (virus, phishing, malware, etc.).
  • Mixing up the functions of the CPU components — ALU (calculations), CU (control), Registers (temporary storage).
  • Confusing verification (checking data is entered correctly) with validation (checking data is reasonable).
  • Confusing bits and bytes — 1 byte = 8 bits. File sizes are in bytes; data transfer speeds are often in bits.
  • Mixing up RAM and ROM — RAM is volatile (loses data when power off); ROM is non-volatile.

✅ Key Points to Remember

  • Know the stages of the systems development life cycle and what happens at each stage.
  • Be able to create and modify spreadsheets, databases, and presentations in the practical examination.
  • Know the advantages and disadvantages of different input and output devices for specific situations.
  • Understand the difference between verification methods (double entry, visual check) and validation checks (range check, type check, etc.).
  • Understand the difference between system software and application software with examples.

Number System Conversions

Converting between binary, denary, and hexadecimal is a core skill:

Binary to Denary

Each binary digit represents a power of 2, from right to left:

128 64 32 16 8 4 2 1

Example: 10110100 = 128 + 32 + 16 + 4 = 180

Binary to Hexadecimal

Group binary digits into sets of 4 (from the right) and convert each group:

Example: 10110100 → 1011 0100 → B 4 → B4

Denary to Binary

Repeatedly divide by 2 and record remainders:

Example: Convert 157 to binary

157 ÷ 2 = 78 r 1

78 ÷ 2 = 39 r 0

39 ÷ 2 = 19 r 1

19 ÷ 2 = 9 r 1

9 ÷ 2 = 4 r 1

4 ÷ 2 = 2 r 0

2 ÷ 2 = 1 r 0

1 ÷ 2 = 0 r 1

Reading remainders from bottom to top: 10011101

In the practical examination, always save your work regularly and in the correct file format. Follow the instructions precisely — missing a small formatting requirement can cost marks.

Worked Example 1: Binary to Hexadecimal Conversion

Problem

Convert the 16-bit binary number 1101011010101100 to hexadecimal.

Solution

Group into 4 bits from the right: 1101 0110 1010 1100

1101 = 13 = D

0110 = 6 = 6

1010 = 10 = A

1100 = 12 = C

Answer: D6AC

Worked Example 2: Spreadsheet Formula

Problem

A spreadsheet has sales data in cells B2:B10. Write formulas to calculate: (a) total sales, (b) average sales, (c) commission at 5% on sales over $1000.

Solution

(a) =SUM(B2:B10)

(b) =AVERAGE(B2:B10)

(c) =IF(B2>1000, B2*0.05, 0) — copied down for each row

Worked Example 3: Database Query

Problem

A student database has fields: StudentID, Name, Class, Age, Grade. Write a query to find all students in Class 10A who are 16 years old or older and have a grade of A or B.

Solution

SELECT * FROM Students

WHERE Class = "10A" AND Age >= 16 AND Grade IN ("A", "B")

ORDER BY Name;

Practice Questions

Question 1

Convert the denary number 237 to 8-bit binary and then to hexadecimal.

Answer: Binary: 11101101; Hexadecimal: ED

Question 2

Explain the difference between RAM and ROM, giving two examples of what each is used for in a computer system.

Answer: RAM (volatile, temporary storage): stores currently running programs and data. ROM (non-volatile, permanent): stores BIOS/boot instructions. RAM examples: open applications, clipboard. ROM examples: firmware, startup instructions.

Question 3

A business wants to create a mail merge to send personalised letters to 500 customers. Describe the steps involved and the files needed.

Answer: (1) Create letter template in word processor with merge fields. (2) Create data source (database/spreadsheet) with customer details. (3) Link data source to letter. (4) Insert merge fields for name, address, etc. (5) Preview and complete merge to generate individual letters.

🎯 Examination Tips

  • For number conversion questions, show your working — method marks are available.
  • For database questions, know how to create queries using criteria and sorting.
  • When discussing security, give specific examples — "firewall" is better than "security software".
  • For presentation questions, apply design principles — consistency, readability, appropriate use of images.
  • In spreadsheet questions, be able to use formulae, functions (SUM, AVERAGE, IF, etc.), and create charts.
