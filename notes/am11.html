Binomial Expansions

0606

IGCSE Content

1. Pascal's Triangle

The coefficients in the expansion of (a+b)ⁿ come from Pascal's triangle:

(a+b)² = a² + 2ab + b² \\ (a+b)³ = a³ + 3a²b + 3ab² + b³ \\ (a+b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴

2. Binomial Coefficients

\binom{n}{r} = \frac{n!}{r!(n-r)!} = {}^nC_r

3. Binomial Theorem (Positive Integer n)

(a+b)^n = \sum_{r=0}^{n} \binom{n}{r} a^{n-r} b^r
= a^n + \binom{n}{1}a^{n-1}b + \binom{n}{2}a^{n-2}b² + ... + b^n

4. Finding a Specific Term

The (r+1)th term is:

T_{r+1} = \binom{n}{r} a^{n-r} b^r

5. Substituting Values

Use binomial expansion to approximate powers:

(1 + x)^5 ≈ 1 + 5x + 10x² + 10x³ + ... \quad \text{(for small } x\text{)}

AS & A2 Content

1. Binomial Expansion for Rational n

(1 + x)^n = 1 + nx + \frac{n(n-1)}{2!}x² + \frac{n(n-1)(n-2)}{3!}x³ + ... \quad (|x| < 1)

Valid for any real n, including negative and fractional, provided |x| < 1.

2. Approximation

\sqrt{1+x} = (1+x)^{1/2} ≈ 1 + \frac{x}{2} - \frac{x²}{8} + ...
