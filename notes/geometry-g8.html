Transformations & Matrices

geometry-g8

📘 IGCSE Content

Types of Transformation

  • Translation: Slide; vector (a, b)
  • Reflection: Mirror line; x-axis, y-axis, y = x, y = −x
  • Rotation: Centre, angle, direction (clockwise/anticlockwise)
  • Enlargement: Centre, scale factor k

Properties

  • Translation, rotation, reflection preserve shape and size (isometries)
  • Enlargement preserves shape but changes size
  • Area scale factor = k²

📗 AS Level Content

Matrix Representation

Reflection in x-axis: [[1,0],[0,-1]]
Reflection in y-axis: [[-1,0],[0,1]]
Rotation 90° anticlockwise: [[0,-1],[1,0]]
Enlargement scale k: [[k,0],[0,k]]

Combined Transformations

  • Matrix multiplication: apply rightmost matrix first

📙 A2 Level Content

Inverse Transformations

  • Inverse of matrix M: M⁻¹ where MM⁻¹ = I
  • Reflection is self-inverse
  • Rotation by θ: inverse is rotation by −θ

📝 Last-Minute Summary

  • Translation: Vector (a, b)
  • Reflection: Mirror line
  • Rotation: Centre, angle, direction
  • Enlargement: Centre, scale factor k; area = k²
  • Matrix form: Reflection, rotation, enlargement
