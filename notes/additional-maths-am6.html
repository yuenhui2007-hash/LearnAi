Logarithmic & Exponential Functions

Laws of Logarithms

logₐ a = 1
logₐ 1 = 0
logₐ(xy) = logₐ x + logₐ y
logₐ(xy) = logₐ x − logₐ y
logₐ(xⁿ) = n logₐ x

Exponential Growth and Decay

y = y₀eᵏᵗ (growth if k > 0, decay if k < 0)
y = y₀aᵗ
Worked Example

Solve: 2ˣ = 32.

x = log₂ 32 = 5

Worked Example — Logarithmic

Solve: log₂(x + 3) + log₂(x − 1) = 4.

log₂[(x+3)(x−1)] = 4 → (x+3)(x−1) = 16

x² + 2x − 3 = 16 → x² + 2x − 19 = 0

x = −2 ± √(4 + 76)2 = −1 ± √20 = −1 ± 2√5

Since x > 1 (from domain), x = −1 + 2√5

Worked Example — Exponential Decay

A radioactive substance decays according to M = M₀e⁻⁰·⁰⁵ᵗ. Find the half-life.

M = M₀/2 → e⁻⁰·⁰⁵ᵗ = 1/2 → −0.05t = ln(1/2) = −ln 2

t = ln 20.05 ≈ 13.9 years

Key Point: When solving log equations, always check that your solutions are in the domain (arguments of logs must be positive).

📝 Quick Summary

  • log(xy) = log x + log y
  • log(x/y) = log x − log y
  • log(xⁿ) = n log x
  • Exponential: y = y₀eᵏᵗ
  • Check domain for log equations

💡 Exam Tips

  • Learn the laws of logarithms — they are used in many topics.
  • Always check the domain when solving log equations.
  • For exponential equations, take logs of both sides.
  • ln and log₁₀ are both used; know when each is appropriate.
