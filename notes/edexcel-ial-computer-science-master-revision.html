ECS1: Algorithms

Detailed Notes

1. Algorithms

  • Step-by-step instructions to solve problems
  • Flowcharts and pseudocode

2. Programming Constructs

  • Sequence, selection (if), iteration (loops)

3. Data Types

  • Integer, real, string, Boolean, character

4. Testing

  • Syntax errors, logic errors, runtime errors

Last-Minute Summary

  • Algorithm: step-by-step solution
  • Pseudocode: informal language
  • Flowchart: graphical representation
  • Syntax error: breaking language rules

Exam Tips

  • Use meaningful variable names
  • Indent code for readability
  • Test with boundary values
  • Trace tables help find logic errors

ECS2: Data Structures

Detailed Notes

1. Data Structures

  • Arrays, lists, stacks, queues

2. Searching

  • Linear search, binary search

3. Sorting

  • Bubble sort, merge sort

4. Databases

  • Tables, records, fields, keys

Last-Minute Summary

  • Array: collection of same data type
  • Linear search: check each item
  • Binary search: divide and conquer
  • Primary key: unique identifier

Exam Tips

  • Binary search requires sorted data
  • Bubble sort: compare adjacent elements
  • Merge sort: divide, sort, merge
  • Normalisation reduces data redundancy

ECS3: Hardware

Detailed Notes

1. CPU

  • ALU, CU, registers
  • Von Neumann architecture

2. Memory

  • RAM (volatile), ROM (non-volatile)
  • Cache, virtual memory

3. Storage

  • HDD, SSD, optical, magnetic

4. Input/Output

  • Devices and their purposes

Last-Minute Summary

  • ALU: arithmetic and logic
  • CU: controls operations
  • RAM: volatile, fast access
  • ROM: non-volatile, stores BIOS

Exam Tips

  • Fetch-decode-execute cycle
  • Cache: faster than RAM, smaller
  • SSD faster than HDD, no moving parts
  • Virtual memory uses HDD as RAM extension

ECS4: Networks

Detailed Notes

1. Network Types

  • LAN, WAN, PAN, VPN

2. Network Hardware

  • Router, switch, hub, NIC

3. Protocols

  • TCP/IP, HTTP, HTTPS, FTP

4. Security

  • Firewall, encryption, authentication

Last-Minute Summary

  • LAN: local area network
  • WAN: wide area network
  • Router: connects networks
  • TCP/IP: standard protocol suite

Exam Tips

  • HTTP: unsecure; HTTPS: secure
  • Firewall: filters traffic
  • Encryption: scrambles data
  • Strong passwords: length and complexity

ECS5: Databases

Detailed Notes

1. Database Concepts

  • Tables, records, fields, data types

2. Relationships

  • One-to-one, one-to-many, many-to-many

3. SQL

  • SELECT, INSERT, UPDATE, DELETE

4. Normalisation

  • 1NF, 2NF, 3NF

Last-Minute Summary

  • Table: collection of related data
  • Record: row in table
  • Field: column in table
  • Primary key: uniquely identifies record

Exam Tips

  • SQL: Structured Query Language
  • SELECT retrieves data
  • Normalisation reduces redundancy
  • Foreign key links tables

ECS6: Boolean Logic

Detailed Notes

1. Boolean Logic

  • AND, OR, NOT, XOR
  • Truth tables

2. Logic Gates

  • AND, OR, NOT, NAND, NOR

3. Binary

  • Converting between binary and denary
  • Binary addition

4. Hexadecimal

  • Converting between binary and hex

Last-Minute Summary

  • AND: both inputs true = true
  • OR: either input true = true
  • NOT: reverses input
  • 1 hex digit = 4 binary digits

Exam Tips

  • Draw truth tables for all gates
  • NAND and NOR are universal gates
  • Binary addition: 1+1 = 10 (carry 1)
  • Hex used in memory addresses and colours

ECS7: Software Engineering

Detailed Notes

1. SDLC

  • Analysis, design, implementation, testing, evaluation, maintenance

2. Programming Paradigms

  • Procedural, object-oriented, functional

3. OOP Concepts

  • Classes, objects, inheritance, encapsulation, polymorphism

4. Software Engineering

  • Agile, waterfall methodologies

Last-Minute Summary

  • SDLC: software development life cycle
  • OOP: object-oriented programming
  • Class: blueprint; Object: instance
  • Inheritance: child inherits from parent

Exam Tips

  • Waterfall: sequential, rigid
  • Agile: iterative, flexible
  • Encapsulation: hiding internal details
  • Polymorphism: same method, different behaviour
