Trigonometric Ratios & Identities

Trigonometry relates angles to side lengths in triangles and is fundamental in physics, engineering, and navigation.

Basic Definitions (Right-Angled Triangle)

Pythagorean Identities

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ

Worked Example

Given sin θ = 3/5 and θ is acute, find cos θ and tan θ.

cos²θ = 1 − 9/25 = 16/25 → cos θ = 4/5

tan θ = sin θ/cos θ = 3/4

Key Point: Learn the exact values table by heart. Cambridge exam questions often expect you to recognise these without a calculator.

Sine & Cosine Rules

Sine Rule

asin A = bsin B = csin C

Use when given: two angles and one side (AAS/ASA), or two sides and a non-included angle (SSA — ambiguous case).

Cosine Rule

a² = b² + c² − 2bc cos A
cos A = b² + c² − a²2bc

Use when given: three sides (SSS), or two sides and included angle (SAS).

Area of Triangle

Area = 12ab sin C
Worked Example

In triangle ABC, a = 7, b = 5, C = 60°. Find c and the area.

c² = 49 + 25 − 2(7)(5)cos 60° = 74 − 35 = 39 → c = √39

Area = 12(7)(5)sin 60° = 35√34 ≈ 15.16

Exam-Style Question

Question: In triangle ABC, AB = 8 cm, BC = 10 cm, angle ABC = 40°. Find angle BAC. [4]

Solution: Using sine rule: 10sin A = 8sin 40° (M1). sin A = 10 sin 40°8 = 0.8035 (M1). A = 53.5° or 126.5° (A1). Since 126.5° + 40° < 180°, both are valid. A = 53.5° or 126.5° (A1)

Ambiguous Case (SSA): When using sine rule with two sides and a non-included angle, there may be two possible triangles. Always check if both solutions are valid (sum of angles < 180°).

Trigonometric Equations

Solve trig equations by finding the principal value, then using the period and symmetry of trig functions.

Strategy
  1. Rearrange to isolate the trig function.
  2. Find the principal value using inverse trig.
  3. Use CAST diagram or graph to find all solutions in the required interval.
  4. Add multiples of the period (2π or π) if the interval extends beyond one cycle.
Worked Example

Solve: sin x = 0.5 for 0° ≤ x ≤ 360°

Principal: x = 30°. Sin is positive in Q1 and Q2.

x = 30° or 150°

Worked Example — Multiple Angles

Solve: cos 2x = 0.5 for 0 ≤ x ≤ 2π

2x = π3, 5π3, 7π3, 11π3

x = π6, 5π6, 7π6, 11π6

Worked Example — Using Identities

Solve: 2sin²x + cos x − 1 = 0 for 0 ≤ x ≤ 2π

Replace sin²x with 1 − cos²x: 2(1−cos²x) + cos x − 1 = 0

2cos²x − cos x − 1 = 0 → (2cos x + 1)(cos x − 1) = 0

cos x = −1/2 or cos x = 1

x = 2π3, 4π3, 0, 2π

Key Point: When solving equations with multiple angles (e.g., sin 2x), find all values of the multiple angle first, then divide. Remember to extend the interval for the multiple angle accordingly.

  • y = −sin x: reflection in x-axis

Exam-Style Question

Question: The depth of water in a harbour is modelled by d = 5 + 3 sin(πt6), where t is hours after midnight. Find the maximum depth and the first time after midnight when the depth is 4 metres. [5]

Solution: Max = 5 + 3 = 8 metres (B1). 5 + 3 sin(πt/6) = 4 → sin(πt/6) = −1/3 (M1). πt/6 = π + 0.3398 = 3.4814 (M1). t = 6.65 hours ≈ 06:39 (A1, A1)

📝 Quick Summary

  • sin²θ + cos²θ = 1; 1 + tan²θ = sec²θ
  • Sine rule: a/sin A = b/sin B = c/sin C
  • Cosine rule: a² = b² + c² − 2bc cos A
  • Area = ½ab sin C
  • Period of sin/cos = 2π; period of tan = π

💡 Exam Tips

  • Learn exact values for 0, π/6, π/4, π/3, π/2 by heart.
  • Always check whether the question wants degrees or radians.
  • When using the sine rule with SSA, watch for the ambiguous case.
  • For trig equations, use the CAST diagram to find all solutions.
  • When sketching trig graphs, label amplitude, period, and key points.
