Networks, Internet & Security

ict-i2

📘 IGCSE Content

Network Types

  • LAN (Local Area Network): Limited area; home, school, office
  • WAN (Wide Area Network): Spans large distances; internet is largest WAN
  • WLAN: Wireless LAN using WiFi

Network Hardware

  • Router: Connects networks; directs traffic
  • Switch: Connects devices within LAN
  • Hub: Broadcasts to all devices (less efficient)
  • Modem: Converts digital to analogue signals

Internet & WWW

  • Internet: Global network of networks
  • WWW (World Wide Web): Information system using HTTP
  • URL: Uniform Resource Locator; web address
  • IP Address: Unique identifier for devices

📗 AS Level Content

Network Topologies

  • Bus: Single cable; cheap but single point of failure
  • Star: Central hub/switch; easy to manage; hub failure critical
  • Mesh: Multiple paths; redundant but expensive

Security Threats

  • Malware: Viruses, worms, trojans, ransomware, spyware
  • Phishing: Fake emails/websites to steal credentials
  • DDoS: Overwhelm server with traffic

📙 A2 Level Content

Security Measures

  • Firewall: Filters traffic based on rules
  • Encryption: SSL/TLS for websites; AES for data
  • Authentication: Passwords, 2FA, biometrics
  • VPN: Encrypted tunnel for secure remote access
  • Penetration testing: Ethical hacking to find vulnerabilities

📝 Last-Minute Summary

  • LAN vs WAN: Local vs Wide area
  • Router, Switch, Hub: Network hardware
  • Internet ≠ WWW
  • Threats: Malware, phishing, DDoS
  • Protection: Firewall, encryption, 2FA, VPN
