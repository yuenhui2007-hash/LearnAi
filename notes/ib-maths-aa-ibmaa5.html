Calculus

IB DP Mathematics: Analysis & Approaches HL/SL — Topic 5

Overview

Calculus (Topic 5) is the capstone of IB Mathematics AA, covering limits, differentiation, integration, and differential equations. HL students study additional techniques and Maclaurin series. This topic is the most heavily weighted in all exam papers.

5.1 Limits & Continuity

lim(x→a) f(x) = L means f(x) approaches L as x approaches a
A function is continuous at x = a if lim(x→a) f(x) = f(a)

Important limits:
lim(x→0) sin x / x = 1
lim(x→0) (e^x − 1) / x = 1
lim(x→∞) (1 + 1/x)^x = e

5.2 Differentiation

Power rule: d/dx(x^n) = nx^(n−1)
Product rule: d/dx(uv) = u'v + uv'
Quotient rule: d/dx(u/v) = (u'v − uv')/v²
Chain rule: d/dx(f(g(x))) = f'(g(x)) × g'(x)

d/dx(sin x) = cos x
d/dx(cos x) = −sin x
d/dx(tan x) = sec²x
d/dx(e^x) = e^x
d/dx(ln x) = 1/x

Applications

  • Gradient of a curve: f'(x) at a point.
  • Tangents and normals: tangent gradient = f'(a); normal gradient = −1/f'(a).
  • Increasing/decreasing: f'(x) > 0 → increasing; f'(x) < 0 → decreasing.
  • Stationary points: f'(x) = 0. Second derivative test: f''(x) > 0 → minimum; f''(x) < 0 → maximum.
  • Optimisation: find maximum/minimum in a practical context.
  • Kinematics: s = displacement, v = ds/dt, a = dv/dt = d²s/dt².

Worked Example 1: Optimisation

Question: Find the dimensions of a rectangle with perimeter 20 m that maximises area.

Solution:

2x + 2y = 20 → y = 10 − x
A = x(10 − x) = 10x − x²
dA/dx = 10 − 2x = 0 → x = 5
y = 5 → square with side 5 m gives maximum area = 25 m²

5.3 Integration

∫ x^n dx = x^(n+1)/(n+1) + C (n ≠ −1)
∫ 1/x dx = ln|x| + C
∫ e^x dx = e^x + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C

Definite integral: ∫[a,b] f(x) dx = F(b) − F(a)
Area between curves: ∫[a,b] (f(x) − g(x)) dx where f(x) ≥ g(x)

Worked Example 2: Area

Question: Find the area enclosed by y = x² and y = x.

Solution:

Intersection: x² = x → x = 0, 1
Area = ∫[0,1] (x − x²) dx = [x²/2 − x³/3]₀¹ = ½ − ⅓ = 1/6

5.4 Differential Equations

First-order separable: dy/dx = f(x)g(y) → ∫ dy/g(y) = ∫ f(x) dx
Slope fields: sketch approximate solutions from dy/dx = F(x,y)
Euler's method: y_(n+1) = y_n + h × F(x_n, y_n)

5.5 Maclaurin Series [HL only]

f(x) = f(0) + f'(0)x + f''(0)x²/2! + f'''(0)x³/3! + ...

e^x = 1 + x + x²/2! + x³/3! + ...
sin x = x − x³/3! + x⁵/5! − ...
cos x = 1 − x²/2! + x⁴/4! − ...
ln(1+x) = x − x²/2 + x³/3 − ... (|x| < 1)

HL Exam Focus

May 2024 HL Paper 3: Maclaurin series approximation with error bound using Lagrange remainder.

Common Misconceptions

  • Constant of integration: Always include +C for indefinite integrals.
  • Area below x-axis: Definite integrals can be negative — area is the absolute value.
  • Chain rule: Remember to multiply by the derivative of the inner function.
  • Stationary points: f'(x) = 0 is necessary but not sufficient — check the second derivative or sign change.

Exam-Specific Information

  • Paper 1: 6–8 questions on differentiation, integration, and their applications.
  • Paper 2: Modelling and optimisation problems, area and volume calculations.
  • Paper 3 (HL): Proof-based calculus, Maclaurin series, and advanced differential equations.
  • IA: Calculus-based explorations (optimisation, area, kinematics) are very popular.

Practice Questions

  • Differentiate f(x) = x² ln x.
  • Find the equation of the tangent to y = e^(2x) at x = 0.
  • Evaluate ∫[0,π/2] sin²x dx.
  • Solve dy/dx = y/x given y(1) = 2.
  • HL: Find the first three non-zero terms of the Maclaurin series for cos(2x).

Last-Minute Summary

  • Differentiation: power, product, quotient, chain rules.
  • Applications: tangents, stationary points, optimisation, kinematics.
  • Integration: reverse differentiation; definite integrals give areas.
  • Area between curves: ∫(top − bottom) dx.
  • Separable differential equations: separate variables and integrate both sides.
  • HL: Maclaurin series = Taylor series centred at 0.

Exam Tips

  • Read each question carefully and identify the command term before answering.
  • Show all working — method marks are generous in IB Mathematics.
  • Give exact answers unless asked for decimal approximations.
  • Always include +C for indefinite integrals.
  • For optimisation, check endpoints as well as stationary points.
