Binomial Expansions

Binomial Theorem

(a + b)ⁿ = aⁿ + n1aⁿ⁻¹b + n(n−1)2!aⁿ⁻²b² + ... + bⁿ

(1 + x)ⁿ = 1 + nx + n(n−1)2!x² + n(n−1)(n−2)3!x³ + ...
(valid for |x| < 1 when n is not a positive integer)
Worked Example

Expand (1 + 2x)⁵ up to x³.

= 1 + 5(2x) + 5×42(2x)² + 5×4×36(2x)³

= 1 + 10x + 40x² + 80x³ + ...

Worked Example — Negative Index

Expand (1 − x)⁻² up to x³.

= 1 + (−2)(−x) + (−2)(−3)2(−x)² + (−2)(−3)(−4)6(−x)³

= 1 + 2x + 3x² + 4x³ + ... valid for |x| < 1

Worked Example — Finding Coefficients

Find the coefficient of x² in (2 + 3x)⁶.

General term: ⁶Cᵣ × 2⁶⁻ʳ × (3x)ʳ

For x²: r = 2. Coefficient = ⁶C₂ × 2⁴ × 3² = 15 × 16 × 9 = 2160

Key Point: For expansions of (a + bx)ⁿ, rewrite as aⁿ(1 + bx/a)ⁿ first. The expansion is valid for |bx/a| < 1.

📝 Quick Summary

  • (1 + x)ⁿ = 1 + nx + n(n−1)x²/2! + ...
  • Valid for |x| < 1 when n not a positive integer
  • General term: ⁿCᵣ aⁿ⁻ʳ bʳ
  • Rewrite (a + bx)ⁿ as aⁿ(1 + bx/a)ⁿ

💡 Exam Tips

  • Remember the validity condition |x| < 1 for non-positive integer indices.
  • For (a + bx)ⁿ, factor out aⁿ first.
  • Be careful with signs when the expansion contains negative terms.
  • The general term in (a + b)ⁿ is ⁿCᵣ aⁿ⁻ʳ bʳ.
