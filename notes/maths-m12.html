Hypothesis Testing Basics

Hypothesis testing is a statistical method for making decisions about a population based on sample data.

Key Terms

TermDefinition
Null hypothesis (H₀)The default assumption (e.g., p = 0.5)
Alternative hypothesis (H₁)The claim we test against H₀ (e.g., p ≠ 0.5, p > 0.5, p < 0.5)
Significance level (α)Probability of rejecting H₀ when it is true (Type I error)
p-valueProbability of obtaining results at least as extreme as observed
Test statisticA value calculated from sample data
Critical valueThe threshold for rejecting H₀
Type I errorRejecting H₀ when it is true (false positive)
Type II errorNot rejecting H₀ when it is false (false negative)
Hypothesis Testing Procedure
  1. State H₀ and H₁ clearly.
  2. Choose significance level α (usually 5% or 1%).
  3. Calculate the test statistic from sample data.
  4. Find the critical value or p-value.
  5. Compare and make a decision: reject or do not reject H₀.
  6. Write a conclusion in context.

Binomial Hypothesis Test

For testing a population proportion using the binomial distribution.

Worked Example

A coin is tossed 20 times and 15 heads are obtained. Test at 5% whether the coin is biased towards heads.

H₀: p = 0.5, H₁: p > 0.5 (one-tailed)

X ~ B(20, 0.5) under H₀

P(X ≥ 15) = 1 − P(X ≤ 14) = 1 − 0.9793 = 0.0207

Since 0.0207 < 0.05, reject H₀. There is evidence the coin is biased towards heads.

Worked Example — Two-Tailed

Test at 5% whether a die is biased if 4 sixes are obtained in 24 throws.

H₀: p = 1/6, H₁: p ≠ 1/6 (two-tailed)

X ~ B(24, 1/6). E(X) = 4.

P(X ≤ 4) = 0.424 (from tables or calculator)

Two-tailed p-value = 2 × 0.424 = 0.848 > 0.05

Do not reject H₀. Insufficient evidence of bias.

Key Point: For a two-tailed test at significance level α, compare the p-value with α (not α/2) when using the p-value method. When using critical values, split α equally between both tails.
3

Normal Hypothesis Test

For testing a population mean when the population is normally distributed or the sample size is large.

Test statistic: Z = x̄ − μσ/√n
Worked Example

A sample of 50 students has mean height 172 cm. Test at 5% whether the mean has increased from the known population mean of 170 cm (σ = 8).

H₀: μ = 170, H₁: μ > 170

Z = 172 − 1708/√50 = 21.131 ≈ 1.768

Critical value at 5% (one-tailed) = 1.645

Since 1.768 > 1.645, reject H₀. Evidence suggests mean height has increased.

Exam-Style Question

Question: A machine fills bags with sugar. A sample of 36 bags has mean 1.02 kg. Test at 1% whether the machine is overfilling, given σ = 0.05 kg. [6]

Solution: H₀: μ = 1.00, H₁: μ > 1.00 (B1). Z = 1.02−1.000.05/6 = 2.4 (M1, M1). Critical value = 2.326 (B1). 2.4 > 2.326 → Reject H₀ (A1). Evidence that machine is overfilling (A1).

📝 Quick Summary

  • H₀ = null hypothesis; H₁ = alternative hypothesis
  • Reject H₀ if p-value < α or test statistic > critical value
  • Type I error = reject true H₀; Type II error = accept false H₀
  • Binomial test: X ~ B(n, p₀) under H₀
  • Normal test: Z = (x̄ − μ)/(σ/√n)

💡 Exam Tips

  • Always state H₀ and H₁ in terms of the parameter (e.g., μ or p).
  • Check whether the test is one-tailed or two-tailed before finding critical values.
  • Write conclusions in context, not just 'reject H₀'.
  • For binomial tests, use cumulative probabilities to avoid rounding errors.
  • For normal tests, ensure you use σ/√n (standard error), not just σ.
