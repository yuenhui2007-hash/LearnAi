Spreadsheets, Word Processing & Presentation

Topic i7 — Revision Summary

📝 Last-Minute Summary

  • Word: Styles ensure consistency; Mail Merge personalizes bulk documents; Headers/Footers repeat content.
  • Spreadsheet references: Relative (A1), Absolute ($A$1), Mixed ($A1 or A$1).
  • Key functions: SUM, AVERAGE, MAX, MIN, COUNT, IF, VLOOKUP, SUMIF, COUNTIFS, ROUND.
  • Charts: Column/Bar (compare), Line (trend), Pie (proportion), Scatter (correlation).
  • What-If: Goal Seek (one input), Scenario Manager (sets of inputs), Data Table (range), Solver (optimization).
  • Validation: Restrict input types; protection prevents accidental edits.
  • Presentation: Master slide for consistency; 6×6 rule; minimal transitions; speaker notes.
  • Advanced: INDEX+MATCH > VLOOKUP; Pivot Tables summarize; Power Query transforms; VBA automates.
  • Modelling: Separate inputs/calculations/outputs; sensitivity analysis; document assumptions.
  • Exam tip: For spreadsheet questions, always specify cell references (absolute vs relative) when copying formulas.

🔑 Key Terms

  • Cell, Range, Formula, Function, Relative reference, Absolute reference, Mixed reference
  • VLOOKUP, HLOOKUP, INDEX, MATCH, IF, Nested IF, SUMIF, COUNTIFS, PMT, NPV
  • Pivot Table, Slicer, Conditional formatting, Data validation, Goal Seek, Scenario, Solver
  • Mail Merge, Master slide, Transition, Animation, Speaker notes
  • Macro, VBA, Power Query, Power Pivot, DAX, Dashboard, KPI

🎯 Exam Tips

  • In spreadsheet questions, explain WHY absolute references are needed for constants/tax rates.
  • For chart selection: compare categories = bar/column; trend over time = line; part of whole = pie.
  • Presentation answers: mention audience engagement, visual hierarchy, and accessibility.
  • Mail Merge: list the four steps — main doc, data source, merge fields, complete merge.
