Cognitive Approach

IB DP Psychology HL/SL — Approach 2

Overview

The Cognitive Approach (Approach 2) examines internal mental processes such as memory, perception, thinking, and decision-making. It uses models and theories to explain behaviour and is assessed in Paper 1. Understanding memory models and cognitive biases is essential for both exam success and the IA.

2.1 Memory Models

Multi-Store Model (Atkinson & Shiffrin, 1968)

  • Sensory memory: brief storage of sensory information (iconic ~0.5s, echoic ~3–4s).
  • Short-term memory (STM): limited capacity (7±2 items), limited duration (~18–30s), acoustic encoding.
  • Long-term memory (LTM): theoretically unlimited capacity and duration, semantic encoding.

Information flows from sensory → STM → LTM through attention and rehearsal.

Working Memory Model (Baddeley & Hitch, 1974)

  • Central executive: controls attention, coordinates subsystems.
  • Phonological loop: verbal/acoustic information (articulatory control process + phonological store).
  • Visuospatial sketchpad: visual and spatial information.
  • Episodic buffer (added 2000): integrates information across modalities and links to LTM.

2.2 Thinking & Decision-Making

Schema Theory

  • Schemas are cognitive frameworks that organise knowledge.
  • They help process information efficiently but can lead to distortion (e.g., Bartlett's "War of the Ghosts" — memory reconstruction).

Heuristics & Biases

  • Availability heuristic: judge probability by ease of recall (e.g., fear of flying vs. driving).
  • Representativeness heuristic: judge by stereotype (e.g., assuming a shy person is a librarian).
  • Anchoring bias: over-rely on first piece of information.
  • Confirmation bias: seek information that supports existing beliefs.

Dual Process Theory

  • System 1: fast, automatic, intuitive, prone to biases.
  • System 2: slow, effortful, logical, analytical.
  • Kahneman's research shows most everyday decisions use System 1.

2.3 Cognitive Processing

  • Bottom-up processing: perception driven by sensory input (data-driven).
  • Top-down processing: perception influenced by expectations and schemas (concept-driven).
  • Interactive processing: both occur simultaneously.

2.4 Reliability of Cognitive Processes

  • Reconstructive memory: memories are not exact recordings but reconstructions influenced by schemas, expectations, and post-event information (Loftus's eyewitness testimony research).
  • Flashbulb memories: vivid, detailed memories of emotionally significant events — but research shows they are not necessarily more accurate than ordinary memories (Neisser).

Common Misconceptions

  • Memory as video recording: Memory is reconstructive, not reproductive — it changes over time.
  • STM capacity: 7±2 refers to chunks, not individual items — chunking increases capacity.
  • Schemas: They are not "errors" — they are adaptive but can lead to distortion.

Practice Questions

  • Describe the multi-store model of memory and outline one strength and one limitation.
  • Explain how schemas can lead to distortion in memory, using one empirical study.
  • Discuss the role of heuristics in decision-making, with reference to Kahneman's research.
  • Evaluate the working memory model as an explanation of short-term memory.

Last-Minute Summary

  • Multi-store model: sensory → STM → LTM via attention and rehearsal.
  • Working memory: central executive, phonological loop, visuospatial sketchpad, episodic buffer.
  • Schema theory: cognitive frameworks that organise knowledge but can distort memory.
  • Heuristics: availability, representativeness, anchoring, confirmation bias.
  • Dual process: System 1 (fast, intuitive) vs. System 2 (slow, analytical).
  • Memory is reconstructive, not a perfect recording.

Exam Tips

  • Name studies and researchers — this earns application marks.
  • Draw the multi-store model and working memory model diagrams accurately.
  • For evaluation, consider ecological validity, methodology, and alternative explanations.
  • In essays, integrate cognitive explanations with biological or sociocultural approaches.
