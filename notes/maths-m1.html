Quadratics

Syllabus reference: Cambridge 9709 / 0580 — Pure Mathematics 1

The Quadratic Equation

A quadratic equation has the form:

ax² + bx + c = 0, where a ≠ 0

Methods of Solving

  • Factorisation — rewrite as (px + q)(rx + s) = 0
  • Quadratic formula — x = (−b ± √(b² − 4ac)) / 2a
  • Completing the square — rewrite as a(x + p)² + q = 0

The Discriminant

The discriminant Δ = b² − 4ac determines the nature of the roots:

  • Δ > 0 — two distinct real roots
  • Δ = 0 — one repeated real root
  • Δ < 0 — no real roots (complex roots)

Completing the Square

For ax² + bx + c:

a(x + b/2a)² + (c − b²/4a)

This form reveals the vertex and is useful for sketching and finding maximum/minimum values.

Exam Tips

  • Always check if factorisation is possible before using the formula.
  • When sketching, label the vertex, roots, and y-intercept.
  • For inequalities, sketch the curve to determine the correct regions.
