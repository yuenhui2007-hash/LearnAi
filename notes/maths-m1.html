Quadratics

9709 · 0580

Detailed Notes

1. Solving Quadratics

  • Factorising: x² + bx + c = (x+p)(x+q) where pq=c, p+q=b.
  • Formula: x = (-b ± √(b²-4ac)) / 2a
  • Completing the square: ax² + bx + c = a(x+h)² + k

2. Discriminant

Δ = b² - 4ac
  • Δ > 0: 2 distinct real roots.
  • Δ = 0: 1 repeated real root.
  • Δ < 0: No real roots.

3. Quadratic Graphs

y = ax² + bx + c. Vertex at x = -b/2a. Axis of symmetry. Maximum if a<0, minimum if a>0.

5. Completing the Square

  • Method: ax² + bx + c = a(x + b/2a)² + (c − b²/4a)
  • Turning point: (−b/2a, c − b²/4a)
  • Use: Finding max/min, sketching curves, solving equations

📐 Worked Example

Question: Express 2x² − 8x + 5 in the form a(x + p)² + q

2x² − 8x + 5 = 2(x² − 4x) + 5
= 2[(x − 2)² − 4] + 5
= 2(x − 2)² − 8 + 5
= 2(x − 2)² − 3
Turning point: (2, −3)

6. Inequalities

  • Linear: Solve like equations, but reverse inequality when ×/÷ by negative
  • Quadratic: Factorise, sketch, find regions satisfying inequality
  • Critical values: Where expression = 0 or is undefined
Forgetting to reverse the inequality sign when multiplying or dividing by a negative number.

Problem-Solving Strategies

  • Read twice: Once for understanding, once for details
  • Identify the topic: What technique is being tested?
  • Write down formulae: Before substituting values
  • Check answers: Does the answer make sense? Re-substitute if possible

Common Algebraic Mistakes

  • (a + b)² ≠ a² + b² (it's a² + 2ab + b²)
  • √(a + b) ≠ √a + √b
  • 1/(a + b) ≠ 1/a + 1/b
  • When squaring both sides, check for extraneous solutions
Dividing by a variable without considering if it could be zero. Always state "assuming x ≠ 0" or check separately.

5. Polynomials & Factor Theorem

  • Factor Theorem: If f(a) = 0, then (x − a) is a factor of f(x)
  • Remainder Theorem: f(a) gives the remainder when f(x) is divided by (x − a)
  • Cubic equations: Try factors of the constant term to find roots

📐 Worked Example

Question: Show that (x − 2) is a factor of f(x) = x³ − 3x² − 4x + 12, and hence factorise fully.

f(2) = 8 − 12 − 8 + 12 = 0 ✓
So (x − 2) is a factor.
Divide: x³ − 3x² − 4x + 12 = (x − 2)(x² − x − 6)
= (x − 2)(x − 3)(x + 2)
f(x) = (x − 2)(x − 3)(x + 2)

6. Simultaneous Equations — Three Methods

MethodWhen to useSteps
SubstitutionOne variable already isolatedSubstitute expression into other equation
EliminationCoefficients easily matchedMultiply equations, add/subtract to eliminate one variable
GraphicalApproximate solutions acceptablePlot both equations, find intersection
Always check your solution by substituting back into both original equations.

Last-Minute Summary

  • Factorise, formula, or complete the square
  • Δ = b²-4ac; >0 (2 roots), =0 (1 root), <0 (no real)
  • Vertex at x = -b/2a

📐 Worked Example

Question: Differentiate y = 3x⁴ + 2x² − 5x + 7

Solution:
dy/dx = 3(4x³) + 2(2x) − 5(1) + 0
dy/dx = 12x³ + 4x − 5
Answer: dy/dx = 12x³ + 4x − 5
Forgetting the +c (constant of integration) for indefinite integrals. You'll lose a mark!
The chain rule: if y = f(g(x)), then dy/dx = f'(g(x)) × g'(x). Use for functions inside functions.

⚡ Quick Recall

  • d/dx(xⁿ) = nxⁿ⁻¹
  • ∫xⁿ dx = xⁿ⁺¹/(n+1) + c
  • Chain rule: dy/dx = dy/du × du/dx
  • Stationary points: dy/dx = 0; d²y/dx² > 0 = min
