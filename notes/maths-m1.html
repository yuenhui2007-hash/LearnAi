Solving Quadratic Equations

A quadratic equation has the form ax² + bx + c = 0 where a ≠ 0. Quadratic equations model projectile motion, profit maximisation, and many engineering applications.

Method 1: Factorising

Express as two brackets: ax² + bx + c = (px + q)(rx + s)

Factorising Strategy
  1. Check for a common factor first.
  2. For x² + bx + c: find two numbers that multiply to c and add to b.
  3. For ax² + bx + c: test factor pairs of a and c.
  4. Expand mentally to verify.
Worked Example — Monic

Solve: x² + 5x + 6 = 0

Numbers: +2 and +3 (product 6, sum 5)

(x + 2)(x + 3) = 0 → x = −2 or x = −3

Worked Example — Non-Monic

Solve: 6x² + 7x − 3 = 0

Try (2x + 3)(3x − 1) = 6x² − 2x + 9x − 3 = 6x² + 7x − 3 ✓

x = −3/2 or x = 1/3

Method 2: Quadratic Formula

x = −b ± √(b² − 4ac)2a

Derivation: Starting with ax² + bx + c = 0, divide by a and complete the square to derive the formula.

Worked Example

Solve: 2x² − 7x + 3 = 0

a = 2, b = −7, c = 3

x = 7 ± √(49 − 24)4 = 7 ± 54

x = 3 or x = ½

Method 3: Completing the Square

Rewrite in the form a(x + h)² + k. Essential for finding vertices.

Worked Example

Express in completed square form: x² + 6x + 5

Half of 6 is 3: (x + 3)² = x² + 6x + 9

x² + 6x + 5 = (x + 3)² − 9 + 5 = (x + 3)² − 4

Vertex: (−3, −4)

Worked Example — a ≠ 1

Express: 2x² − 8x + 7

2(x² − 4x) + 7 = 2[(x − 2)² − 4] + 7 = 2(x − 2)² − 1

Key Point: When a ≠ 1, factor a out from the x-terms before completing the square, then multiply the constant adjustment by a.
Exam-Style Question with Mark Scheme

Question: (a) Express 2x² − 12x + 13 in the form a(x + b)² + c. [3]
(b) Hence write down the coordinates of the minimum point. [1]
(c) Find the set of values of x for which 2x² − 12x + 13 ≤ 5. [3]

Mark Scheme:

(a) 2(x² − 6x) + 13 (M1) → 2[(x − 3)² − 9] + 13 (M1) → 2(x − 3)² − 5 (A1)

(b) Minimum point at (3, −5) (B1)

(c) 2x² − 12x + 8 ≤ 0 → x² − 6x + 4 ≤ 0 (M1) → x = 6 ± √202 = 3 ± √5 (M1) → 3 − √5 ≤ x ≤ 3 + √5 (A1)

The Discriminant

The discriminant Δ = b² − 4ac determines the nature of roots without solving.

Value of ΔNature of RootsGraph
Δ > 0Two distinct real rootsCrosses x-axis twice
Δ = 0One repeated real rootTouches x-axis at vertex
Δ < 0No real rootsDoes not cross x-axis
Δ = perfect squareRational roots—
Worked Example

Find the discriminant: 3x² + 2x + 5 = 0

Δ = 4 − 60 = −56 → No real roots

Worked Example — Unknown Coefficient

Find k for equal roots: x² + kx + 4 = 0

Δ = k² − 16 = 0 → k = ±4

Worked Example — Range of Values

Find p for two distinct real roots: 2x² + 3x + p = 0

Δ = 9 − 8p > 0 → p < 9/8

Key Point: Always calculate Δ explicitly. For "equal roots" write Δ = 0; for "distinct" write Δ > 0; for "real" write Δ ≥ 0.
Exam-Style Question

Question: Find the range of k for which x² + kx + (k + 3) = 0 has real roots. [4]

Solution: Δ = k² − 4(k + 3) = k² − 4k − 12 ≥ 0 (M1)

(k − 6)(k + 2) ≥ 0 (M1) → k ≤ −2 or k ≥ 6 (A1, A1 for both intervals correct)

Quadratic Graphs

The graph of y = ax² + bx + c is a parabola.

Key Features

FeatureHow to Find
Shapea > 0: ∪ (minimum); a < 0: ∩ (maximum)
Vertexx = −b/2a, then substitute
Axis of symmetryx = −b/2a
y-intercept(0, c)
x-interceptsSolve ax² + bx + c = 0

Transformations

  • y = (x − h)²: horizontal translation h units right
  • y = x² + k: vertical translation k units up
  • y = ax²: vertical stretch, |a| > 1 narrower, 0 < |a| < 1 wider
  • y = −x²: reflection in x-axis
  • y = a(x − h)² + k: vertex at (h, k)
Worked Example — Sketching

Sketch: y = x² − 4x + 3

Shape: ∪ (a = 1 > 0)

Vertex: x = 2, y = −1 → (2, −1)

Roots: (x−1)(x−3) = 0 → x = 1, 3

y-intercept: (0, 3)

Worked Example — No Real Roots

Sketch: y = x² + 2x + 3

Δ = 4 − 12 = −8 < 0. No real roots.

Vertex: (−1, 2). Entire parabola above x-axis.

Key Point: When sketching, always draw a clearly shaped parabola (∪ or ∩), label the vertex, roots (if any), and y-intercept.

Quadratic Inequalities

Solve by finding critical values and testing intervals or sketching.

Strategy
  1. Rearrange so one side is zero and x² coefficient is positive.
  2. Find roots of the corresponding equation.
  3. Sketch the parabola, marking roots.
  4. Determine where parabola is above (>0) or below (<0) x-axis.
Worked Example

Solve: x² − 5x + 6 > 0

Roots: x = 2, 3. ∪-shape. Want above x-axis.

Answer: x < 2 or x > 3

Worked Example — ≤

Solve: 2x² + x − 6 ≤ 0

Roots: x = −2, 3/2. Want on or below x-axis.

Answer: −2 ≤ x ≤ 3/2

Worked Example — Rearrangement

Solve: x² < 9

x² − 9 < 0 → (x−3)(x+3) < 0 → −3 < x < 3

Common Error: x < ±3 is meaningless — always rearrange to standard form.

Important: If multiplying/dividing an inequality by a negative number, reverse the sign. It is safer to rearrange so the x² coefficient is positive.
Exam-Style Question

Question: Find the set of values of x for which 3x² − 10x + 3 < 0. [3]

Solution: (3x − 1)(x − 3) = 0 → x = 1/3 or x = 3 (M1). ∪-shape. Below x-axis between roots (M1).

Answer: 1/3 < x < 3 (A1)

📝 Quick Summary

  • Quadratic formula: x = (−b ± √(b² − 4ac))/2a
  • Discriminant Δ = b² − 4ac determines number of roots
  • Vertex at x = −b/2a
  • Complete square: x² + bx + c = (x + b/2)² − (b/2)² + c
  • For inequalities: find roots, sketch, determine regions

💡 Exam Tips

  • Always state the quadratic formula before substituting — method marks are awarded even if arithmetic is wrong.
  • Check factorising first — it saves time.
  • When sketching, label vertex, roots, and y-intercept clearly.
  • If Δ < 0, state 'no real roots' rather than 'no solutions'.
  • Use a sketch for inequalities — never rely on mental algebra alone.
  • For 'show that' questions, write each step clearly.
