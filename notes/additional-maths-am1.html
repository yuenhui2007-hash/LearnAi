Set Notation & Definitions

A set is a well-defined collection of distinct objects called elements.

Key Notation

SymbolMeaningExample
∈Is an element of3 ∈ {1,2,3}
∉Is not an element of5 ∉ {1,2,3}
⊂Is a subset of{1,2} ⊂ {1,2,3}
∪Union{1,2} ∪ {2,3} = {1,2,3}
∩Intersection{1,2} ∩ {2,3} = {2}
A′Complement of AEverything in ξ not in A
n(A)Number of elementsn({1,2,3}) = 3

Special Sets

  • Universal set (ξ): All objects under consideration
  • Empty set (∅): Contains no elements
  • ℕ: Natural numbers {1, 2, 3, ...}
  • ℤ: Integers {..., −2, −1, 0, 1, 2, ...}
  • ℚ: Rational numbers
  • ℝ: Real numbers
Worked Example

Given ξ = {1,2,...,10}, A = {2,4,6,8,10}, B = {1,2,3,4,5}:

A ∪ B = {1,2,3,4,5,6,8,10}

A ∩ B = {2,4}

A′ = {1,3,5,7,9}

Inclusion-Exclusion: n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
Worked Example — Venn Diagram

In a class of 30, 18 study Maths, 15 study Physics, 7 study both. How many study neither?

n(M ∪ P) = 18 + 15 − 7 = 26

Neither = 30 − 26 = 4

📝 Quick Summary

  • ∪ = union, ∩ = intersection, A′ = complement
  • n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
  • De Morgan: (A ∪ B)′ = A′ ∩ B′
  • Venn diagrams help visualise set problems

💡 Exam Tips

  • Always draw a Venn diagram for problems with two or three sets.
  • Remember the inclusion-exclusion principle.
  • (A ∪ B)′ = A′ ∩ B′ (De Morgan's Law).
  • For three sets: n(A∪B∪C) = n(A)+n(B)+n(C)−n(A∩B)−n(B∩C)−n(A∩C)+n(A∩B∩C).
