Integration Basics

Integration is the reverse process of differentiation. It is used to find areas, volumes, and solve differential equations.

Key Point: Never forget the constant of integration (+ c) for indefinite integrals. Definite integrals (with limits) do not need it because it cancels out.

Definite Integration & Area

∫ab f(x) dx = [F(x)]ab = F(b) − F(a)

Area Under a Curve

The definite integral gives the signed area between the curve and the x-axis.

Worked Example

Find the area between y = x², the x-axis, x = 1 and x = 3.

Area = ∫13 x² dx = [x³3]13 = 9 − 13 = 263

Worked Example — Area Below Axis

Find the total area enclosed by y = x² − 4 and the x-axis.

Roots: x = ±2. Between −2 and 2, the curve is below the axis.

∫−22 (x² − 4) dx = [x³3 − 4x]−22 = (83−8) − (−83+8) = −323

Total area = 323 (take absolute value)

Key Point: When a curve crosses the x-axis within the interval, split the integral at each root and take the absolute value of each part to find total area.

Integration by Substitution

Substitution simplifies integrals by changing the variable.

Strategy
  1. Choose u = g(x) where g'(x) appears in the integral.
  2. Find du/dx and rearrange to replace dx.
  3. Substitute and integrate with respect to u.
  4. Replace u with the original expression.
Worked Example

Integrate: ∫ 2x(x² + 1)³ dx

Let u = x² + 1, du/dx = 2x → dx = du/2x

∫ 2x · u³ · du2x = ∫ u³ du = u⁴4 + c = (x²+1)⁴4 + c

Integration by Parts

∫ u dv = uv − ∫ v du
Choosing u (LIATE rule)
  1. Logarithmic functions
  2. Inverse trig functions
  3. Algebraic (polynomial) functions
  4. Trigonometric functions
  5. Exponential functions
Worked Example

Integrate: ∫ x eˣ dx

u = x, dv = eˣ dx → du = dx, v = eˣ

∫ x eˣ dx = x eˣ − ∫ eˣ dx = x eˣ − eˣ + c = eˣ(x − 1) + c

Worked Example — Twice by Parts

Integrate: ∫ x² sin x dx

First: u = x², dv = sin x dx → du = 2x dx, v = −cos x

= −x² cos x + ∫ 2x cos x dx

Second: u = 2x, dv = cos x dx → du = 2 dx, v = sin x

= −x² cos x + 2x sin x − 2∫ sin x dx = −x² cos x + 2x sin x + 2 cos x + c

Key Point: Integration by parts is useful when the integrand is a product of two different types of functions. Sometimes you need to apply it twice.

📝 Quick Summary

  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + c (n ≠ −1)
  • ∫ 1/x dx = ln|x| + c
  • Definite integral = F(b) − F(a)
  • Area below axis: take absolute value
  • Integration by parts: ∫ u dv = uv − ∫ v du

💡 Exam Tips

  • Always include + c for indefinite integrals.
  • When finding area, sketch the curve first to see if it crosses the x-axis.
  • For substitution, change the limits for definite integrals to avoid back-substitution.
  • Integration by parts: choose u using LIATE.
  • Check your answer by differentiating — you should get the original integrand.
