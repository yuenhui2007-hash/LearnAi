Software, OS & Applications

📘 IGCSE Content

System Software

  • Operating System (OS): Manages hardware and software resources
  • Functions: Memory management, process scheduling, file management, security, user interface
  • Examples: Windows, macOS, Linux, Android, iOS

Application Software

  • Word processors: Microsoft Word, Google Docs
  • Spreadsheets: Excel, Google Sheets
  • Databases: Access, MySQL
  • Web browsers: Chrome, Firefox, Safari

Software Types

  • Open source: Source code available; free to modify (Linux)
  • Proprietary: Closed source; licensed (Windows)

📗 AS Level Content

Utility Software

  • Anti-virus: Detects and removes malware
  • Disk defragmenter: Optimises file storage
  • Backup software: Copies data for recovery
  • Compression tools: ZIP, RAR

OS Concepts

  • Multitasking: Running multiple programs simultaneously
  • Virtual memory: Using disk space as RAM extension

📙 A2 Level Content

Programming Languages

  • Low-level: Assembly, machine code — close to hardware
  • High-level: Python, Java, C++ — human-readable
  • Compiled: Translated to machine code before running (C++)
  • Interpreted: Translated line by line (Python)

📝 Last-Minute Summary

  • OS: Manages hardware/software
  • Applications: Word, Excel, browsers
  • Open source: Free to modify
  • Proprietary: Licensed, closed source
  • Compiled vs Interpreted: Pre-translated vs line-by-line
