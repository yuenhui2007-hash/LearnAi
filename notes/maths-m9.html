Line Equations

Vector form: r = a + tb
Cartesian form: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c
Worked Example

Line through (1, 2, 3) parallel to (2, −1, 4).

r = (1, 2, 3) + t(2, −1, 4)

📝 Quick Summary

  • |r| = √(a² + b² + c²)
  • a · b = a₁b₁ + a₂b₂ + a₃b₃
  • Perpendicular: a · b = 0
  • Angle: cos θ = (a·b)/(|a||b|)
  • Line: r = a + tb

💡 Exam Tips

  • When finding angle, ensure vectors point from/to same point
  • For perpendicular lines, direction vectors have dot product = 0
  • Magnitude always positive
  • Vector AB = b − a
