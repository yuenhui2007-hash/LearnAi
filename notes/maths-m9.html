Vector Representation

A vector has both magnitude and direction. Vectors are essential in physics, engineering, and computer graphics.

Notation

  • Column vector: ab or (a, b) in 2D; ab
    c     in 3D
  • Unit vectors: i = 10, j = 01, k = 00
    1
  • Position vector: vector from origin to point P
Magnitude: |ab| = √(a² + b²)
Direction: θ = tan⁻¹(ba)
Worked Example

Find the magnitude and direction of a = 34.

|a| = √(9 + 16) = 5

θ = tan⁻¹(43) ≈ 53.1°

Vector Operations

Addition and Subtraction

Add/subtract corresponding components.

Worked Example

Given a = 2−1 and b = 34, find a + b and a − b.

a + b = 53

a − b = −1−5

Scalar Multiplication

Multiplies magnitude by the scalar. Negative scalars reverse direction.

Dot (Scalar) Product

a · b = |a||b| cos θ = a₁b₁ + a₂b₂ + a₃b₃
Worked Example

Find the angle between a = 12 and b = 3−1.

a · b = 3 − 2 = 1

|a| = √5, |b| = √10

cos θ = 1√50 = 15√2 → θ ≈ 81.9°

Key Point: Two vectors are perpendicular if and only if their dot product is zero (a · b = 0).

Equation of a Line

Vector Equation of a Line

r = a + λb
where a = position vector of a point on the line, b = direction vector, λ = scalar parameter
Worked Example

Find the vector equation of the line through (1, 2) with direction vector 31.

r = 12 + λ31

Cartesian Form

From r = xy = a₁a₂ + λb₁b₂:

x − a₁b₁ = y − a₂b₂ (= λ)
Worked Example

Convert r = 2−1 + λ43 to Cartesian form.

x − 24 = y + 13 → 3(x−2) = 4(y+1) → 3x − 4y = 10

Exam-Style Question

Question: Find the point of intersection of the lines r = 12 + s21 and r = 31 + t1−1. [5]

Solution: 1 + 2s = 3 + t and 2 + s = 1 − t (M1, M1). Solving: s = 1/3, t = −4/3 (A1). Point = 5/37/3 (A1, A1)

📝 Quick Summary

  • Magnitude |a| = √(a₁² + a₂² + a₃²)
  • Dot product: a · b = |a||b| cos θ = a₁b₁ + a₂b₂ + a₃b₃
  • Perpendicular vectors: a · b = 0
  • Line: r = a + λb
  • Cartesian: (x−a₁)/b₁ = (y−a₂)/b₂ = (z−a₃)/b₃

💡 Exam Tips

  • Always draw a diagram for vector problems.
  • The dot product a · b = 0 means the vectors are perpendicular.
  • For line equations, the direction vector can be scaled by any non-zero constant.
  • When finding intersections, equate components and solve simultaneously.
  • Remember: vectors have magnitude and direction, but position vectors also have a specific location.
