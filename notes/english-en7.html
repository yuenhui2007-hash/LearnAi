IELTS Reading Strategies

Exam: IELTS Academic / General Training — Reading Module

Overview

The IELTS Reading test consists of 3 passages with 40 questions. You have 60 minutes. No extra time for transferring answers.

Question Types

  • Multiple choice
  • True / False / Not Given (or Yes / No / Not Given)
  • Matching headings to paragraphs
  • Matching information to paragraphs
  • Sentence completion
  • Summary / note / table / flow-chart completion
  • Diagram labelling
  • Short-answer questions

Key Strategies

  • Skimming — read quickly for main idea (2–3 min per passage)
  • Scanning — locate specific information using keywords
  • Keyword matching — find synonyms and paraphrases, not exact words
  • Time management — 20 minutes per passage; harder passages last

True / False / Not Given Tips

  • True — the statement agrees with the information in the passage
  • False — the statement contradicts the information
  • Not Given — the information is not mentioned at all
  • The hardest part is distinguishing False from Not Given. If the passage says the opposite → False. If not mentioned → Not Given.

  • Write answers directly on the answer sheet — no transfer time.
  • Spelling matters; grammar matters for sentence completion.
  • Answer every question — no negative marking.
