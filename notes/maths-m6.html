Arithmetic Progressions

An arithmetic progression (AP) is a sequence where each term increases by a constant difference.

n-th term: aₙ = a + (n − 1)d
Sum of n terms: Sₙ = n2[2a + (n − 1)d] = n2(a + l)
where a = first term, d = common difference, l = last term
Worked Example

The 5th term of an AP is 14 and the 10th term is 29. Find a and d.

a + 4d = 14 and a + 9d = 29

Subtract: 5d = 15 → d = 3. Then a = 14 − 12 = 2

Worked Example — Sum

Find the sum of the first 20 terms of the AP: 3, 7, 11, 15, ...

a = 3, d = 4

S₂₀ = 202[6 + 19(4)] = 10 × 82 = 820

Exam-Style Question

Question: The sum of the first n terms of an AP is given by Sₙ = 2n² + 5n. Find the first term and common difference. [4]

Solution: a = S₁ = 2 + 5 = 7 (B1). S₂ = 8 + 10 = 18, so a₂ = 18 − 7 = 11 (M1). d = 11 − 7 = 4 (A1, A1)

Key Point: If Sₙ is given as a formula, the first term is S₁ and the second term is S₂ − S₁. From these you can find a and d.

Geometric Progressions

A geometric progression (GP) is a sequence where each term is multiplied by a constant ratio.

n-th term: aₙ = arⁿ⁻¹
Sum of n terms: Sₙ = a(1 − rⁿ)1 − r (r ≠ 1)
Sum to infinity: S∞ = a1 − r (|r| < 1)
Worked Example

The 3rd term of a GP is 12 and the 6th term is 96. Find a and r.

ar² = 12 and ar⁵ = 96

Divide: r³ = 8 → r = 2. Then a = 12/4 = 3

Worked Example — Sum to Infinity

Find S∞ for the GP: 8, 4, 2, 1, ...

a = 8, r = 1/2. |r| < 1, so S∞ exists.

S∞ = 81 − 1/2 = 16

Key Point: S∞ only exists when |r| < 1. If |r| ≥ 1, the series diverges (does not converge to a finite sum).

Binomial Expansion

The binomial theorem expands expressions of the form (a + b)ⁿ.

(a + b)ⁿ = aⁿ + n1aⁿ⁻¹b + n(n−1)2!aⁿ⁻²b² + ... + bⁿ

(1 + x)ⁿ = 1 + nx + n(n−1)2!x² + n(n−1)(n−2)3!x³ + ...
(valid for |x| < 1 when n is not a positive integer)
Worked Example

Expand (1 + 2x)⁵ up to x³.

= 1 + 5(2x) + 5×42(2x)² + 5×4×36(2x)³

= 1 + 10x + 40x² + 80x³ + ...

Worked Example — Negative/Fractional Index

Expand (1 − x)⁻² up to x³, stating the validity.

= 1 + (−2)(−x) + (−2)(−3)2(−x)² + (−2)(−3)(−4)6(−x)³

= 1 + 2x + 3x² + 4x³ + ... valid for |x| < 1

Key Point: For expansions with negative or fractional indices, always state the range of validity: |x| < 1 for (1 + x)ⁿ. For (a + bx)ⁿ, rewrite as aⁿ(1 + bx/a)ⁿ first.

📝 Quick Summary

  • AP: aₙ = a + (n−1)d; Sₙ = n/2[2a + (n−1)d]
  • GP: aₙ = arⁿ⁻¹; Sₙ = a(1−rⁿ)/(1−r); S∞ = a/(1−r) for |r|<1
  • Binomial: (1+x)ⁿ = 1 + nx + n(n−1)x²/2! + ...
  • Binomial validity: |x| < 1 for non-positive integer n

💡 Exam Tips

  • For AP/GP problems, write down the formula before substituting values.
  • Always check whether a GP converges before using S∞.
  • For binomial expansions with negative indices, be careful with signs.
  • Remember to state the range of validity for binomial expansions with non-positive integer indices.
  • When finding a and d (or a and r), set up simultaneous equations using the given terms.
