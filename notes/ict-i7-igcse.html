📘 Subject Context

Spreadsheets, Word Processing & Presentation is a fundamental topic in IGCSE ICT. Understanding both the theory and practical applications of information and communication technology is essential for the modern world and the examination.

IGCSE ICT tests theoretical knowledge, practical skills, and the ability to apply ICT to solve problems. Paper 1 (Theory) tests knowledge and understanding; Paper 2 (Practical) tests hands-on skills in word processing, spreadsheets, databases, and presentations.

Spreadsheets, Word Processing & Presentation

Topic i7 — Productivity Software & Data Analysis

📘 IGCSE Content

1.1 Word Processing

Software for creating, editing, and formatting text documents. Examples: Microsoft Word, Google Docs, LibreOffice Writer.

  • Formatting: Font (typeface, size, colour, bold, italic, underline), paragraph alignment (left, centre, right, justified), line spacing, indentation, bullets/numbering.
  • Styles: Predefined sets of formatting (Heading 1, Heading 2, Normal, Title). Applying styles ensures consistency and enables automatic table of contents generation.
  • Tables: Organize data in rows/columns; merge cells, borders, shading, formulas.
  • Mail Merge: Combine a template document with a data source (spreadsheet/database) to generate personalized letters, labels, or emails. Steps: create main document → link data source → insert merge fields → preview → complete merge.
  • Headers and Footers: Repeated content at top/bottom (page numbers, document title, date). Different for first page or odd/even pages.
  • Page Layout: Margins, orientation (portrait/landscape), paper size, columns, section breaks.
  • Proofing tools: Spell check, grammar check, thesaurus, word count, readability statistics.

1.2 Spreadsheets

A grid of cells identified by column letter and row number (e.g., B5). Used for calculations, data analysis, and visualization. Examples: Microsoft Excel, Google Sheets, LibreOffice Calc.

  • Cell references:
    • Relative: A1 — changes when copied (A1 → B2 if dragged down-right).
    • Absolute: $A$1 — stays fixed when copied.
    • Mixed: $A1 or A$1 — one dimension fixed, one relative.
  • Formulas: Begin with =. Arithmetic: +, −, *, /, ^ (power). Example: =B2*C2+D2.
  • Common functions:
    • SUM(range): Adds values. =SUM(A1:A10)
    • AVERAGE(range): Mean of values.
    • MAX/MIN(range): Largest/smallest value.
    • COUNT(range): Counts numeric cells.
    • COUNTA(range): Counts non-empty cells.
    • IF(condition, true_value, false_value): Conditional logic. =IF(A1>=50,"Pass","Fail")
    • AND/OR/NOT: Logical combinations. =IF(AND(A1>0,A1<100),"Valid","Invalid")
    • VLOOKUP(lookup_value, table_array, col_index, range_lookup): Searches first column of table, returns value from specified column. Use FALSE for exact match.
    • CONCATENATE / &: Join text. =A1 & " " & B1

1.3 Spreadsheet Features

  • Conditional formatting: Automatically formats cells based on their values (e.g., red if negative, green if positive, colour scales, data bars).
  • Sorting: Arrange data alphabetically/numerically by one or more columns. Ascending (A→Z, 0→9) or Descending.
  • Filtering: Display only rows meeting criteria. Standard filter or advanced filter with custom criteria.
  • Charts/Graphs: Visual representation of data.
    • Column/Bar: Compare categories.
    • Line: Show trends over time.
    • Pie: Show proportions/percentages (must total 100%).
    • Scatter (XY): Show correlation between two variables.
    Chart elements: title, axis labels, legend, data labels, gridlines.
  • Pivot Tables: Summarize large datasets by grouping and aggregating. Drag fields to rows, columns, values, and filters areas.

1.4 Presentation Software

Create slideshows for visual communication. Examples: Microsoft PowerPoint, Google Slides, LibreOffice Impress, Prezi.

  • Slides: Individual pages containing text, images, charts, audio, video.
  • Master Slide: Template controlling default layout, fonts, colours, and backgrounds for all slides. Ensures consistency.
  • Transitions: Animations between slides (fade, slide, wipe). Use sparingly — professional presentations avoid excessive effects.
  • Animations: Effects on individual objects (appear, fly in, fade). Trigger: on click, with previous, after previous.
  • Design principles: Keep text minimal (6×6 rule: max 6 lines, 6 words per line), high contrast, readable fonts, relevant images, consistent colour scheme.
  • Presenter tools: Speaker notes, slide timings, rehearse tool, laser pointer, presenter view (current slide + next slide + notes + timer).

2.1 Advanced Spreadsheet Functions

=IFERROR(VLOOKUP(A2,Products!$A$2:$D$100,3,FALSE),"Not found")
=SUMIF(Sales!B:B,"Electronics",Sales!C:C) // sum C where B = Electronics
=COUNTIFS(Scores!A:A,">=50",Scores!B:B,"Pass") // multiple criteria
=ROUND(A1,2) // round to 2 decimal places
=PMT(interest_rate/12, months, -loan_amount) // loan payment
=NPV(discount_rate, cashflow_range) + initial_investment // net present value
  • Nested IFs: =IF(A1>=80,"A",IF(A1>=70,"B",IF(A1>=60,"C","D")))
  • Lookups: VLOOKUP (vertical), HLOOKUP (horizontal), INDEX+MATCH (more flexible than VLOOKUP, works left-to-right or right-to-left).
  • Date/Time: TODAY(), NOW(), DATE(year,month,day), DATEDIF(start,end,"D"), YEAR(), MONTH(), DAY().
  • Text manipulation: LEFT(), RIGHT(), MID(), LEN(), TRIM(), UPPER(), LOWER(), PROPER(), SUBSTITUTE(), TEXT().
  • Financial: PMT, FV (future value), PV (present value), RATE, NPER, IRR (internal rate of return).

2.2 Data Analysis & What-If Tools

  • Goal Seek: Find input value needed to achieve a desired output. Example: What sales figure is needed for profit = $10,000?
  • Scenario Manager: Save and switch between multiple sets of input values (best case, worst case, expected case).
  • Data Tables: Show results of a formula for multiple input values simultaneously (one-variable or two-variable tables).
  • Solver: Advanced optimization tool finding maximum, minimum, or specific value by changing multiple variables subject to constraints.

2.3 Data Validation & Protection

  • Data validation: Restrict cell input (whole number between 1-100, date within range, list from dropdown, text length).
  • Input messages: Tooltip instructing user what to enter.
  • Error alerts: Stop, Warning, or Information when invalid data entered.
  • Worksheet protection: Lock cells or entire sheets with passwords. Allows view but prevents editing.
  • Workbook protection: Prevent adding, deleting, or hiding sheets.

2.4 Document Production Best Practices

  • Templates: Pre-designed documents ensuring corporate branding, consistency, and efficiency.
  • Version control: Track Changes (Word), Suggesting mode (Google Docs), comments, compare documents.
  • Collaboration: Real-time co-authoring, sharing permissions (view, comment, edit), cloud storage (OneDrive, Google Drive, Dropbox).
  • Accessibility in documents: Heading styles for screen readers, alt text for images, readable fonts (sans-serif for screens), sufficient contrast, table headers.

📙 A2 Level Content

3.1 Spreadsheet Modelling

Spreadsheets are powerful tools for business modelling and decision support:

  • Model design principles: Separate inputs (assumptions), calculations, and outputs. Use distinct colour-coding (e.g., yellow for inputs, green for calculations, blue for outputs). Document assumptions clearly.
  • Sensitivity analysis: Test how changes in input variables affect outputs. Create tornado charts showing which variables have greatest impact.
  • Monte Carlo simulation: Uses random sampling and probability distributions to model uncertainty. Run thousands of iterations to produce probability distributions of outcomes. Add-ins: @RISK, Crystal Ball.
  • Regression analysis: Built-in LINEST function or Data Analysis ToolPak. Finds line of best fit (y = mx + c), R-squared (goodness of fit), standard error.

3.2 Macros & Automation

  • Macros: Recorded sequences of actions or written in VBA (Visual Basic for Applications). Automate repetitive tasks, create custom functions, build user forms.
  • Recording vs Writing: Recording is quick but rigid. Writing VBA allows loops, conditions, error handling, interaction with other Office applications.
  • Security: Macros can carry malware. Enable only from trusted sources. Digital signatures verify macro authenticity.
Sub FormatReport()
Dim ws As Worksheet
Set ws = ThisWorkbook.Sheets("Sales")
ws.Range("A1:Z1").Font.Bold = True
ws.Range("A1:Z1").Interior.Color = RGB(200,220,255)
MsgBox "Formatting complete!"
End Sub

3.3 Business Intelligence & Dashboards

  • Dashboards: Visual summaries of KPIs using charts, gauges, scorecards, and conditional formatting. Update automatically when source data changes.
  • Slicers & Timelines: Interactive filters for pivot tables and pivot charts. Click buttons to filter data dynamically.
  • Power Query (Get & Transform): Import, clean, and transform data from multiple sources (databases, web, CSV, JSON) before analysis.
  • Power Pivot: In-memory data modelling engine. Create relationships between tables, write DAX (Data Analysis Expressions) formulas for complex calculations.

3.4 Document Design & Professional Communication

  • Information design: Structure documents for readability — hierarchy (headings, subheadings), white space, visual grouping, alignment, proximity.
  • Typography: Serif fonts (Times New Roman) for print body text; sans-serif (Arial, Calibri) for screens and headings. Limit to 2–3 fonts per document.
  • Colour theory: Complementary colours for contrast; analogous for harmony. Consider colour blindness (avoid red-green combinations for critical info).
  • Data visualization principles (Tufte): Maximize data-ink ratio; avoid chartjunk; use small multiples; label directly when possible.

💻 Worked Example

Question: Convert denary 157 to 8-bit binary.

Solution:
128 + 16 + 8 + 4 + 1 = 157
1 0 0 1 1 1 0 1
Answer: 10011101
Confusing bits and bytes. 1 byte = 8 bits. File sizes in bytes; transfer speeds in bits.
Fetch-decode-execute: 1) Fetch instruction from memory, 2) Decode operation, 3) Execute. Repeats millions of times/second.

⚡ Quick Recall

  • CPU: ALU + CU + Registers
  • RAM: Volatile; ROM: Non-volatile
  • LAN: Local; WAN: Wide
  • Binary to hex: Group in 4s from right

⚠️ Common Mistakes to Avoid

  • Forgetting that a LAN covers a small geographical area while a WAN covers a large area.
  • Forgetting to convert between binary, denary, and hexadecimal — practise these conversions regularly.
  • Mixing up RAM and ROM — RAM is volatile (loses data when power off); ROM is non-volatile.
  • Confusing verification (checking data is entered correctly) with validation (checking data is reasonable).
  • Confusing an intranet (internal network) with the Internet (global network).

✅ Key Points to Remember

  • Know the hardware components of a computer system and their functions.
  • Be able to create and modify spreadsheets, databases, and presentations in the practical examination.
  • Understand the difference between verification methods (double entry, visual check) and validation checks (range check, type check, etc.).
  • Know the advantages and disadvantages of different input and output devices for specific situations.
  • Understand the difference between system software and application software with examples.

Number System Conversions

Converting between binary, denary, and hexadecimal is a core skill:

Binary to Denary

Each binary digit represents a power of 2, from right to left:

128 64 32 16 8 4 2 1

Example: 10110100 = 128 + 32 + 16 + 4 = 180

Binary to Hexadecimal

Group binary digits into sets of 4 (from the right) and convert each group:

Example: 10110100 → 1011 0100 → B 4 → B4

Denary to Binary

Repeatedly divide by 2 and record remainders:

Example: Convert 157 to binary

157 ÷ 2 = 78 r 1

78 ÷ 2 = 39 r 0

39 ÷ 2 = 19 r 1

19 ÷ 2 = 9 r 1

9 ÷ 2 = 4 r 1

4 ÷ 2 = 2 r 0

2 ÷ 2 = 1 r 0

1 ÷ 2 = 0 r 1

Reading remainders from bottom to top: 10011101

In the practical examination, always save your work regularly and in the correct file format. Follow the instructions precisely — missing a small formatting requirement can cost marks.

Worked Example 1: Binary to Hexadecimal Conversion

Problem

Convert the 16-bit binary number 1101011010101100 to hexadecimal.

Solution

Group into 4 bits from the right: 1101 0110 1010 1100

1101 = 13 = D

0110 = 6 = 6

1010 = 10 = A

1100 = 12 = C

Answer: D6AC

Worked Example 2: Spreadsheet Formula

Problem

A spreadsheet has sales data in cells B2:B10. Write formulas to calculate: (a) total sales, (b) average sales, (c) commission at 5% on sales over $1000.

Solution

(a) =SUM(B2:B10)

(b) =AVERAGE(B2:B10)

(c) =IF(B2>1000, B2*0.05, 0) — copied down for each row

Worked Example 3: Database Query

Problem

A student database has fields: StudentID, Name, Class, Age, Grade. Write a query to find all students in Class 10A who are 16 years old or older and have a grade of A or B.

Solution

SELECT * FROM Students

WHERE Class = "10A" AND Age >= 16 AND Grade IN ("A", "B")

ORDER BY Name;

Practice Questions

Question 1

Convert the denary number 237 to 8-bit binary and then to hexadecimal.

Answer: Binary: 11101101; Hexadecimal: ED

Question 2

Explain the difference between RAM and ROM, giving two examples of what each is used for in a computer system.

Answer: RAM (volatile, temporary storage): stores currently running programs and data. ROM (non-volatile, permanent): stores BIOS/boot instructions. RAM examples: open applications, clipboard. ROM examples: firmware, startup instructions.

Question 3

A business wants to create a mail merge to send personalised letters to 500 customers. Describe the steps involved and the files needed.

Answer: (1) Create letter template in word processor with merge fields. (2) Create data source (database/spreadsheet) with customer details. (3) Link data source to letter. (4) Insert merge fields for name, address, etc. (5) Preview and complete merge to generate individual letters.

🎯 Examination Tips

  • In theory questions, use precise terminology — "volatile" not "forgets data when switched off".
  • For presentation questions, apply design principles — consistency, readability, appropriate use of images.
  • In practical examinations, follow the instructions exactly — missing a small step can lose marks.
  • For number conversion questions, show your working — method marks are available.
  • For database questions, know how to create queries using criteria and sorting.
