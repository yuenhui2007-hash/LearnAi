Mathematical Models

IB DP Mathematics: Applications & Interpretation HL/SL — Topic 6

Overview

Mathematical Models (Topic 6) brings together statistical and algebraic techniques to analyse relationships in data. It covers linear regression, correlation, and hypothesis testing. This topic is central to the data-driven philosophy of Maths AI.

6.1 Linear Regression

Regression line: y = ax + b
a = cov(X,Y) / var(X) = S_xy / S_xx
b = ȳ − a x̄

Use GDC to calculate regression coefficients.
Interpolation (within data range) is reliable; extrapolation is not.

6.2 Correlation

Pearson's r = cov(X,Y) / (σ_X σ_Y)
−1 ≤ r ≤ 1
|r| > 0.8 → strong correlation; |r| < 0.3 → weak correlation
r = 0 → no linear correlation (but may be non-linear)

Correlation does not imply causation.

6.3 Chi-Squared Test

χ² = Σ (O − E)² / E
where O = observed frequency, E = expected frequency

Expected frequency = (row total × column total) / grand total
degrees of freedom = (rows − 1)(columns − 1)
If χ² > critical value (or p-value < α), reject H₀

Worked Example 1: Chi-Squared

Question: Test for association between gender and preference at 5% significance.

Prefer APrefer B
Male3020
Female2525

Solution:

Expected (Male, A) = (50×55)/100 = 27.5
χ² = (30−27.5)²/27.5 + (20−22.5)²/22.5 + (25−27.5)²/27.5 + (25−22.5)²/22.5 = 0.91
df = 1; critical value at 5% = 3.841
0.91 < 3.841 → do not reject H₀ → no significant association

6.4 t-Test

One-sample t-test: compare sample mean to hypothesised value
Two-sample t-test: compare means of two independent samples
Paired t-test: compare means of paired data (before/after)

t = (x̄ − μ₀) / (s/√n)
Compare |t| to critical value or use p-value

Common Misconceptions

  • Correlation vs. causation: A strong correlation does not prove one variable causes the other.
  • r = 0: No linear correlation, but there could be a strong non-linear relationship.
  • Extrapolation: Predicting outside the data range is unreliable regardless of R².
  • Chi-squared: Expected frequencies should be ≥ 5 for valid results.

Practice Questions

  • Given data points (1,3), (2,5), (3,7), (4,9), calculate the regression line and predict y when x = 5.
  • Test whether there is an association between smoking and lung disease using the given contingency table at the 1% level.
  • A sample of 25 students has mean score 72 and standard deviation 8. Test at 5% whether the population mean is 70.

Last-Minute Summary

  • Regression: y = ax + b; use GDC for calculations.
  • Correlation: r measures linear association; −1 ≤ r ≤ 1.
  • Correlation ≠ causation.
  • Chi-squared: Σ(O−E)²/E; df = (r−1)(c−1).
  • t-test: compare means; paired for before/after data.
  • Reject H₀ if p < α or test statistic > critical value.

Exam Tips

  • Read each question carefully and identify the command term before answering.
  • Show all working — method marks are generous in IB Mathematics.
  • Give answers to 3 significant figures unless specified otherwise.
  • State H₀ and H₁ clearly in hypothesis tests.
  • Interpret results in context, not just numerically.
