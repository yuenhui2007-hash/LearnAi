Quadratics

Detailed Notes

1. Solving Quadratics

  • Factorising: x² + bx + c = (x+p)(x+q) where pq=c, p+q=b.
  • Formula: x = (-b ± √(b²-4ac)) / 2a
  • Completing the square: ax² + bx + c = a(x+h)² + k

2. Discriminant

Δ = b² - 4ac
  • Δ > 0: 2 distinct real roots.
  • Δ = 0: 1 repeated real root.
  • Δ < 0: No real roots.

3. Quadratic Graphs

y = ax² + bx + c. Vertex at x = -b/2a. Axis of symmetry. Maximum if a<0, minimum if a>0.

5. Completing the Square

  • Method: ax² + bx + c = a(x + b/2a)² + (c − b²/4a)
  • Turning point: (−b/2a, c − b²/4a)
  • Use: Finding max/min, sketching curves, solving equations

📐 Worked Example

Question: Express 2x² − 8x + 5 in the form a(x + p)² + q

2x² − 8x + 5 = 2(x² − 4x) + 5
= 2[(x − 2)² − 4] + 5
= 2(x − 2)² − 8 + 5
= 2(x − 2)² − 3
Turning point: (2, −3)

6. Inequalities

  • Linear: Solve like equations, but reverse inequality when ×/÷ by negative
  • Quadratic: Factorise, sketch, find regions satisfying inequality
  • Critical values: Where expression = 0 or is undefined
Forgetting to reverse the inequality sign when multiplying or dividing by a negative number.

Problem-Solving Strategies

  • Read twice: Once for understanding, once for details
  • Identify the topic: What technique is being tested?
  • Write down formulae: Before substituting values
  • Check answers: Does the answer make sense? Re-substitute if possible

Common Algebraic Mistakes

  • (a + b)² ≠ a² + b² (it's a² + 2ab + b²)
  • √(a + b) ≠ √a + √b
  • 1/(a + b) ≠ 1/a + 1/b
  • When squaring both sides, check for extraneous solutions
Dividing by a variable without considering if it could be zero. Always state "assuming x ≠ 0" or check separately.

5. Polynomials & Factor Theorem

  • Factor Theorem: If f(a) = 0, then (x − a) is a factor of f(x)
  • Remainder Theorem: f(a) gives the remainder when f(x) is divided by (x − a)
  • Cubic equations: Try factors of the constant term to find roots

📐 Worked Example

Question: Show that (x − 2) is a factor of f(x) = x³ − 3x² − 4x + 12, and hence factorise fully.

f(2) = 8 − 12 − 8 + 12 = 0 ✓
So (x − 2) is a factor.
Divide: x³ − 3x² − 4x + 12 = (x − 2)(x² − x − 6)
= (x − 2)(x − 3)(x + 2)
f(x) = (x − 2)(x − 3)(x + 2)

6. Simultaneous Equations — Three Methods

MethodWhen to useSteps
SubstitutionOne variable already isolatedSubstitute expression into other equation
EliminationCoefficients easily matchedMultiply equations, add/subtract to eliminate one variable
GraphicalApproximate solutions acceptablePlot both equations, find intersection
Always check your solution by substituting back into both original equations.

Last-Minute Summary

  • Factorise, formula, or complete the square
  • Δ = b²-4ac; >0 (2 roots), =0 (1 root), <0 (no real)
  • Vertex at x = -b/2a

Solution:

Functions

Detailed Notes

1. Definitions

Domain = set of inputs. Range = set of outputs. One-to-one: each output from exactly one input.

2. Composite Functions

fg(x) = f(g(x))

3. Inverse Functions

f⁻¹(x): reflect y=f(x) in line y=x. Domain of f = range of f⁻¹.

4. Transformations

  • y = f(x) + a: vertical shift.
  • y = f(x+a): horizontal shift (-a).
  • y = af(x): vertical stretch.
  • y = f(ax): horizontal stretch (1/a).

Coordinate Geometry

Detailed Notes

1. Circle Equation

  • Centre (a,b), radius r: (x−a)² + (y−b)² = r²
  • General: x² + y² + 2gx + 2fy + c = 0; centre (−g,−f), radius √(g²+f²−c)

2. Tangents & Normals

  • Tangent perpendicular to radius at point of contact

Last-Minute Summary

  • Circle: (x−a)² + (y−b)² = r²
  • Tangent ⊥ radius at contact point

Exam Tips

  • Complete the square to find centre and radius from general form
  • To find tangent equation: find gradient of radius, then negative reciprocal
  • Distance from centre to line > radius → no intersection
  • Distance = radius → tangent (one point)

Circular Measure

Detailed Notes

1. Trigonometry

  • SOH CAH TOA
  • Sine rule: a/sin A = b/sin B = c/sin C
  • Cosine rule: a² = b² + c² − 2bc cos A
  • Area: ½ab sin C

2. Radians

  • π rad = 180°
  • Arc length: s = rθ
  • Sector area: A = ½r²θ

Last-Minute Summary

  • Sine rule: a/sin A = b/sin B
  • Cosine rule: a² = b² + c² − 2bc cos A
  • Arc: s = rθ; Sector: A = ½r²θ

Exam Tips

  • When using sine rule for angle: ambiguous case possible (two solutions)
  • Cosine rule for included angle or when all three sides known
  • Convert degrees to radians for calculus (differentiation/integration)
  • Small angle approximations: sin θ ≈ θ, tan θ ≈ θ, cos θ ≈ 1 − θ²/2

Series

Detailed Notes

1. Differentiation

  • Power rule: d/dx(xⁿ) = nxⁿ⁻¹
  • Chain rule: dy/dx = dy/du × du/dx
  • Product rule: d(uv)/dx = u dv/dx + v du/dx
  • Quotient rule: d(u/v)/dx = (v du/dx − u dv/dx)/v²

2. Applications

  • Gradient of curve: dy/dx
  • Stationary points: dy/dx = 0; d²y/dx² > 0 = min, < 0 = max
  • Rate of change: Connected rates

Last-Minute Summary

  • Power rule: d/dx(xⁿ) = nxⁿ⁻¹
  • Chain, product, quotient rules
  • Stationary: dy/dx = 0; d²y/dx² for nature

Exam Tips

  • Always state whether stationary point is max or min (use second derivative or sign test)
  • For parametric: dy/dx = (dy/dt)/(dx/dt)
  • Implicit differentiation: differentiate both sides with respect to x
  • Connected rates: use chain rule to link variables

Differentiation

Detailed Notes

1. Basic Rules

d/dx(xⁿ) = nxⁿ⁻¹
d/dx(sin x) = cos x
d/dx(cos x) = -sin x
d/dx(eˣ) = eˣ
d/dx(ln x) = 1/x

2. Chain Rule

dy/dx = dy/du × du/dx

3. Product and Quotient

d(uv)/dx = u dv/dx + v du/dx
d(u/v)/dx = (v du/dx - u dv/dx) / v²

4. Applications

Gradient of curve, stationary points (dy/dx=0), increasing/decreasing functions.

Integration

Detailed Notes

1. Vectors

  • Components: ai + bj
  • Magnitude: √(a²+b²)
  • Direction: tan θ = b/a

2. Operations

  • Addition: Parallelogram law
  • Dot product: a·b = |a||b|cos θ

Last-Minute Summary

  • Magnitude: √(a²+b²)
  • Dot product: a·b = |a||b|cos θ

Exam Tips

  • Vectors have magnitude and direction
  • Unit vector: divide by magnitude
  • Parallel vectors: scalar multiple of each other
  • Perpendicular vectors: dot product = 0

Vectors

Detailed Notes

1. Forces & Equilibrium

  • Resolve into components
  • ΣF = 0 for equilibrium
  • Triangle of forces

2. Moments

  • Moment = F × d
  • Principle of moments for equilibrium

Last-Minute Summary

  • Resolve forces into components
  • Moment = F × d
  • ΣF = 0 and Σmoments = 0 for equilibrium

Exam Tips

  • Draw free-body diagram for all mechanics problems
  • For inclined planes, resolve parallel and perpendicular to plane
  • Principle of moments: clockwise = anticlockwise about any pivot
  • Friction: F ≤ μR (limiting when equality holds)

Probability

Detailed Notes

1. Kinematics

  • SUVAT: v = u + at; s = ut + ½at²; v² = u² + 2as
  • Graphs: v-t gradient = a, area = s

2. Newton's Laws

  • F = ma
  • Weight = mg
  • Normal reaction, friction, tension

Last-Minute Summary

  • SUVAT equations for constant acceleration
  • F = ma
  • v-t graph: gradient = a, area = displacement

Exam Tips

  • For constant acceleration problems, identify which SUVAT variable is missing
  • Newton's Second Law: resultant force = mass × acceleration
  • Tension same throughout a light inextensible string
  • Friction opposes motion — check direction carefully

Distributions

Detailed Notes

1. Probability

  • AND: Multiply (independent)
  • OR: Add (mutually exclusive)
  • Conditional: P(A|B) = P(A∩B)/P(B)

2. Statistics

  • Mean, median, mode
  • Standard deviation: σ = √(Σ(x−x̄)²/n)
  • Quartiles, interquartile range

Last-Minute Summary

  • AND = multiply; OR = add
  • Conditional: P(A|B) = P(A∩B)/P(B)
  • Standard deviation: σ = √(Σ(x−x̄)²/n)

Exam Tips

  • Venn diagrams help visualise probability relationships
  • Tree diagrams for sequential/multi-stage problems
  • Interquartile range = Q₃ − Q₁ (middle 50% of data)
  • Outliers: values > Q₃ + 1.5×IQR or < Q₁ − 1.5×IQR

Hypothesis Testing

Detailed Notes

1. Distributions

  • Binomial: X ~ B(n,p); P(X=r) = nCr pʳ(1−p)^(n−r); E(X) = np; Var(X) = np(1−p)
  • Normal: X ~ N(μ,σ²); standardise: Z = (X−μ)/σ

2. Normal Approximation

  • Binomial → Normal when np > 5 and n(1−p) > 5
  • Continuity correction needed

Last-Minute Summary

  • Binomial: E(X) = np, Var(X) = np(1−p)
  • Normal: Z = (X−μ)/σ
  • Continuity correction for normal approx to binomial

Exam Tips

  • For binomial: conditions are fixed n, independent trials, constant p, two outcomes
  • Normal distribution: symmetric, bell-shaped, total area = 1
  • Continuity correction: P(X ≤ 10) → P(X < 10.5)
  • Tables give P(Z < z); use symmetry for negative z
