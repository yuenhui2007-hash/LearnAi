Programming Concepts & Algorithms

Topic i8 — Revision Summary

📝 Last-Minute Summary

  • Computational thinking: Decomposition, Abstraction, Pattern Recognition, Algorithmic thinking.
  • Constructs: Sequence, Selection (IF/CASE), Iteration (FOR/WHILE/REPEAT).
  • Data types: Integer, Real, String, Boolean, Char. Arrays = collections accessed by index.
  • Modular programming: Functions (return value) vs Procedures (actions). Parameters by value or reference.
  • Searching: Linear O(n) — unsorted; Binary O(log n) — sorted.
  • Sorting: Bubble O(n²), Insertion O(n²), Merge O(n log n), Quick O(n log n) average.
  • Errors: Syntax (compile-time), Runtime (crash), Logic (wrong output).
  • ADTs: Stack (LIFO), Queue (FIFO), Linked List, Tree (BST).
  • Graphs: BFS (shortest unweighted), DFS (deep exploration), Dijkstra (shortest weighted).
  • OOP: Class, Object, Encapsulation, Inheritance, Polymorphism, Abstraction.
  • Recursion: Base case + recursive case. Elegant but watch stack overflow.
  • Exam tip: For algorithm questions, always write pseudocode with clear indentation. State assumptions (e.g., "array is sorted for binary search").

🔑 Key Terms

  • Algorithm, Pseudocode, Flowchart, Decomposition, Abstraction
  • Variable, Constant, Array, 1D, 2D, Index, Function, Procedure, Parameter
  • Linear search, Binary search, Bubble sort, Insertion sort, Merge sort, Quick sort
  • Syntax error, Runtime error, Logic error, Debugging, Trace table
  • Stack, Queue, Linked List, Tree, BST, Graph, BFS, DFS, Dijkstra
  • OOP, Class, Object, Encapsulation, Inheritance, Polymorphism, Recursion
  • Time complexity, Big O, Hashing, Collision, Adjacency matrix, Adjacency list

🎯 Exam Tips

  • Always show trace tables for iterative algorithms — examiners award method marks.
  • For sorting: state number of passes, comparisons, and swaps clearly.
  • Binary search ONLY works on sorted data — mention this explicitly.
  • Draw trees with root at top, left child smaller, right child larger for BSTs.
  • In OOP questions, explain "is-a" (inheritance) and "has-a" (composition) relationships.
