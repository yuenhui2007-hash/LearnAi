Web Design & HTML/CSS

Topic i6 — Revision Summary

📝 Last-Minute Summary

  • HTML structures content; CSS styles it; JavaScript adds interactivity.
  • Semantic HTML5: header, nav, main, article, section, aside, footer — improves accessibility and SEO.
  • CSS Box Model: content → padding → border → margin. Use box-sizing: border-box.
  • Layouts: Flexbox (1D), Grid (2D). Float is legacy.
  • Responsive: viewport meta tag + media queries + fluid units + flexible images.
  • JavaScript: let/const, arrow functions, DOM manipulation, event listeners.
  • Server-side: PHP, Python (Flask/Django), Node.js. Use parameterized queries to prevent SQL injection.
  • Security: HTTPS, XSS prevention (escape output), CSRF tokens, strong password hashing.
  • REST API: GET/POST/PUT/DELETE + stateless + JSON.
  • SEO: semantic HTML, alt text, mobile-friendly, fast load, backlinks.
  • Exam tip: For web design questions, always mention accessibility (alt text, contrast, keyboard nav) and responsive design.

🔑 Key Terms

  • HTML, CSS, JavaScript, DOM, Element, Tag, Attribute, Selector
  • Box model, Padding, Border, Margin, Flexbox, Grid, Media query
  • Semantic HTML, ARIA, WCAG, Accessibility, Responsive, Mobile-first
  • HTTP, HTTPS, DNS, URL, Server-side, Client-side, Session, Cookie
  • SQL Injection, XSS, CSRF, Parameterized query, REST, API, JSON
  • SEO, Meta tag, Schema, Backlink, PWA, Service worker

🎯 Exam Tips

  • Write clean, indented HTML with closing tags. Exam markers appreciate structure.
  • For CSS specificity: Inline > ID > Class > Element. Use !important sparingly.
  • Always include the viewport meta tag for responsive design questions.
  • Mention W3C validation and accessibility as quality indicators.
  • For security: never trust user input — validate server-side.
