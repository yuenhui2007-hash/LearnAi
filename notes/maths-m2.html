Function Notation & Definitions

A function assigns each element in the domain to exactly one element in the range.

Domain and Range

TermDefinitionExample
DomainAll possible inputs (x-values)f(x) = √x → x ≥ 0
RangeAll possible outputs (y-values)f(x) = x² → f(x) ≥ 0
Natural DomainLargest set for which function is definedf(x) = 1/(x−2) → x ≠ 2

Types of Functions

TypeDefinitionExample
One-one (injective)Different inputs → different outputsf(x) = 2x + 1
Many-oneDifferent inputs → same outputf(x) = x²
Onto (surjective)Range = Codomainf: ℝ→ℝ, f(x) = x³
Worked Example — Domain & Range

For f(x) = √(x − 3), find domain and range.

Domain: x − 3 ≥ 0 → x ≥ 3

Range: Square root ≥ 0 → f(x) ≥ 0

Worked Example — Rational Function

For f(x) = 2x + 1x − 4, find domain.

Denominator ≠ 0: x ≠ 4 → x ∈ ℝ, x ≠ 4

Exam-Style Question

Question: Find the range of f(x) = x² − 4x + 7 for x ∈ ℝ. [3]

Solution: Complete the square: (x − 2)² + 3. Since (x − 2)² ≥ 0, f(x) ≥ 3. Range: f(x) ≥ 3

Composite Functions

A composite function applies one function after another: fg(x) = f(g(x)).

Order Matters: fg(x) means "g first, then f" (read right to left). In general, fg(x) ≠ gf(x).
Worked Example

Given f(x) = 2x + 1 and g(x) = x²:

fg(x) = f(x²) = 2x² + 1

gf(x) = g(2x + 1) = (2x + 1)² = 4x² + 4x + 1

Clearly fg(x) ≠ gf(x).

Worked Example — Domain of Composite

f(x) = √x (x ≥ 0), g(x) = x − 4 (x ∈ ℝ). Find fg(x) and its domain.

fg(x) = √(x − 4)

For fg defined: g(x) must be in domain of f, so x − 4 ≥ 0 → x ≥ 4

Exam-Style Question

Question: Given f(x) = 3x − 2 and g(x) = 2x (x ≠ 0), find fg(x) and state its domain. [4]

Solution: fg(x) = f(2/x) = 3(2/x) − 2 = 6 − 2xx (M1, M1). Domain: x ≠ 0 and 2/x ∈ ℝ → x ≠ 0 (A1, A1)

Inverse Functions

The inverse function f⁻¹ reverses f. A function has an inverse iff it is one-one.

Finding the Inverse

  1. Write y = f(x)
  2. Rearrange to make x the subject
  3. Swap x and y → y = f⁻¹(x)
  4. State domain of f⁻¹ (= range of f)
Worked Example

Find f⁻¹(x) given f(x) = 3x − 2

y = 3x − 2 → x = (y + 2)/3 → f⁻¹(x) = x + 23

Worked Example — Restricted Domain

Find inverse of f(x) = x² + 1 for x ≥ 0.

y = x² + 1 → x = √(y − 1) [positive root since x ≥ 0]

f⁻¹(x) = √(x − 1), domain x ≥ 1 (range of f)

Graphical Relationship

The graph of y = f⁻¹(x) is the reflection of y = f(x) in the line y = x.

PropertyRelationship
Domain of f⁻¹= Range of f
Range of f⁻¹= Domain of f
f(f⁻¹(x))= x
Exam-Style Question

Question: The function f is defined by f(x) = 2x + 3x − 1 for x > 1. Find f⁻¹(x) and state its domain. [5]

Solution: y = 2x + 3x − 1 → y(x−1) = 2x + 3 → x(y−2) = y+3 → x = y+3y−2 (M1, M1). f⁻¹(x) = x+3x−2 (A1). Domain = range of f = x > 2 (B1, B1)

Modulus Function

|x| = x if x ≥ 0
|x| = −x if x < 0

Graphs

TransformationEffect on Graph
y = |f(x)|Reflect negative parts above x-axis
y = f(|x|)Reflect right side to left (symmetric about y-axis)
Worked Example

Solve: |2x − 3| = 5

Case 1: 2x − 3 = 5 → x = 4

Case 2: 2x − 3 = −5 → x = −1

x = 4 or x = −1

Worked Example — Inequality

Solve: |x − 2| < 3

−3 < x − 2 < 3 → −1 < x < 5

Key Point: |x − a| < b means a − b < x < a + b (distance from a is less than b). |x − a| > b means x < a − b or x > a + b.
Exam-Style Question

Question: Solve the inequality |2x − 1| > |x + 3|. [5]

Solution: Square both sides: (2x−1)² > (x+3)² → 4x²−4x+1 > x²+6x+9 → 3x²−10x−8 > 0 (M1, M1). Factorise: (3x+2)(x−4) > 0 (M1). Critical values x = −2/3 and x = 4. ∪-shape, want above x-axis: x < −2/3 or x > 4 (A1, A1)

📝 Quick Summary

  • fg(x) = f(g(x)) — apply g first, then f
  • Inverse: write y = f(x), rearrange for x, swap x and y
  • Domain of f⁻¹ = Range of f; Range of f⁻¹ = Domain of f
  • |x| = x for x ≥ 0; |x| = −x for x < 0
  • Only one-one functions have inverses

💡 Exam Tips

  • Always state the domain when defining a function or its inverse.
  • For composite functions, work from the inside out (right to left).
  • Verify inverses by checking f(f⁻¹(x)) = x.
  • A function must be one-one to have an inverse; if not, restrict the domain.
  • The range of f becomes the domain of f⁻¹, and vice versa.
  • When solving |f(x)| = a, always consider ±a.
