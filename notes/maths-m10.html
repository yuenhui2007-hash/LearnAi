Probability Basics

Probability measures the likelihood of an event occurring, ranging from 0 (impossible) to 1 (certain).

P(A) = Number of favourable outcomesTotal number of possible outcomes

Key Rules

  • Complement: P(A') = 1 − P(A)
  • Addition: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Mutually exclusive: P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B)
  • Independent: P(A ∩ B) = P(A) × P(B)
  • Conditional: P(A|B) = P(A ∩ B)P(B)
Worked Example

A card is drawn from a standard deck. Find P(heart or king).

P(heart) = 13/52, P(king) = 4/52, P(heart ∩ king) = 1/52

P(heart ∪ king) = 1352 + 452 − 152 = 1652 = 413

Worked Example — Conditional

In a class, 60% play football, 40% play basketball, and 25% play both. Find P(basketball | football).

P(B|F) = 0.250.60 = 512

Tree Diagrams & Venn Diagrams

Tree diagrams and Venn diagrams help visualise probability problems involving multiple events.

Worked Example — Tree Diagram

Bag A has 3 red and 2 blue balls. Bag B has 1 red and 4 blue balls. A bag is chosen at random, then a ball. Find P(red).

P(red) = P(choose A) × P(red|A) + P(choose B) × P(red|B)

= 12 × 35 + 12 × 15 = 310 + 110 = 25

Worked Example — Venn Diagram

In a survey of 100 students: 60 like tea, 45 like coffee, 25 like both. How many like neither?

n(T ∪ C) = 60 + 45 − 25 = 80

Neither = 100 − 80 = 20 students

Key Point: Tree diagrams are ideal for sequential events. Venn diagrams are best for showing overlaps between sets. Choose the tool that matches the problem structure.

Combinations & Permutations

Permutations (order matters)

ⁿPᵣ = n!(n−r)!

Combinations (order doesn't matter)

ⁿCᵣ = n!r!(n−r)!
Worked Example

How many ways can 3 people be chosen from 8?

⁸C₃ = 8!3!5! = 8×7×66 = 56

Worked Example

How many 4-letter arrangements from 'MATHS'?

⁵P₄ = 5!1! = 120

Key Point: Use permutations when the order of selection matters (e.g., arranging people in a line). Use combinations when order doesn't matter (e.g., choosing a team).

📝 Quick Summary

  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Independent: P(A ∩ B) = P(A) × P(B)
  • Conditional: P(A|B) = P(A ∩ B)/P(B)
  • ⁿPᵣ = n!/(n−r)!; ⁿCᵣ = n!/[r!(n−r)!]
  • Complement: P(A') = 1 − P(A)

💡 Exam Tips

  • Always check whether events are independent or mutually exclusive.
  • For conditional probability, use the formula P(A|B) = P(A ∩ B)/P(B).
  • Tree diagrams help with sequential probability problems.
  • Permutations = order matters; Combinations = order doesn't matter.
  • When using Venn diagrams, start with the intersection and work outward.
