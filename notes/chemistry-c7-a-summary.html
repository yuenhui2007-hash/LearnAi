C7: Equilibria

9701 (A-Level) · Last-Minute Revision

📚 Comprehensive Revision Summary

Key Formulae:
• See main notes for detailed equations and calculations
  • Dynamic equilibrium: forward/reverse rates equal, concentrations constant, closed system only
  • Le Chatelier: equilibrium shifts to oppose changes in concentration, pressure, temperature
  • Only temperature changes K; concentration and pressure shift position but K stays constant
  • Kc uses concentrations; Kp uses partial pressures; Kp = Kc(RT)^Δn
  • ICE tables: systematic method for equilibrium calculations
  • Brønsted-Lowry: acid = proton donor, base = proton acceptor
  • Buffer: weak acid + conjugate base; pH = pKa + log([A⁻]/[HA])
  • Ksp: precipitation occurs when ionic product > Ksp

💡 Exam Tips

  • Pure solids and liquids are omitted from Kc and Kp expressions
  • Check units of Kc and Kp carefully
  • For weak acid pH, state assumption [H⁺] << [HA]
  • Catalysts do not change K — they speed up attainment only
