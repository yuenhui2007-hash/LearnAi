IGCSE

Equations, Inequalities & Modulus

0606

IGCSE Content

1. Linear Inequalities

Solve like equations, but reverse the inequality when multiplying or dividing by a negative number.

-2x > 6 \Rightarrow x < -3

2. Quadratic Inequalities

Find the roots, sketch the parabola, and read off the regions.

x² - 5x + 6 > 0 \Rightarrow (x-2)(x-3) > 0 \Rightarrow x < 2 \text{ or } x > 3

3. Modulus (Absolute Value)

|x| = \begin{cases} x & \text{if } x ≥ 0 \\ -x & \text{if } x < 0 \end{cases}

The modulus is always non-negative. It represents the distance from zero on the number line.

AS Level Content

1. Modulus Equations

|ax + b| = c \Rightarrow ax + b = c \text{ or } ax + b = -c
|2x - 3| = 5 \Rightarrow 2x - 3 = 5 \text{ or } 2x - 3 = -5 \Rightarrow x = 4 \text{ or } x = -1

2. Modulus Inequalities

|x - a| < b \Rightarrow -b < x - a < b \Rightarrow a - b < x < a + b
|x - a| > b \Rightarrow x - a < -b \text{ or } x - a > b \Rightarrow x < a - b \text{ or } x > a + b

3. Quadratic Inequalities with Parameters

Use the discriminant to find conditions on parameters for a quadratic to be always positive/negative.

x² + kx + 4 > 0 \text{ for all } x \Rightarrow k² - 16 < 0 \Rightarrow -4 < k < 4

A2 Level Content

1. Solving |f(x)| = |g(x)|

Square both sides to eliminate moduli:

|x - 2| = |x + 4| \Rightarrow (x-2)² = (x+4)² \Rightarrow x² - 4x + 4 = x² + 8x + 16 \Rightarrow -12 = 12x \Rightarrow x = -1

2. Graphs of Modulus Functions

The graph of y = |f(x)| reflects any negative part of y = f(x) above the x-axis.

Last-Minute Summary

  • Inequality flip: reverse when multiplying/dividing by a negative.
  • Quadratic inequalities: find roots, sketch, read regions.
  • |x| = a: x = a or x = -a.
  • |x| < a: -a < x < a.
  • |x| > a: x < -a or x > a.
  • |f(x)| = |g(x)|: square both sides.
  • Always positive: a > 0 and discriminant < 0.
