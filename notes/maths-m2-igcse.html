Function Notation & Definitions

A function maps each element of the domain to exactly one element of the range.

TermMeaningExample
DomainAll possible input values (x)f(x) = √x, domain: x ≥ 0
RangeAll possible output values (y)f(x) = x², range: f(x) ≥ 0
CodomainSet containing the rangeUsually all real numbers

Types of Functions

TypeDefinitionExample
One-one (injective)Different inputs → different outputsf(x) = 2x + 1
Many-oneDifferent inputs → same outputf(x) = x²
Onto (surjective)Range = Codomainf: ℝ→ℝ, f(x) = x³

Composite Functions

A composite function applies one function after another.

fg(x) = f(g(x))

Read right to left: apply g first, then f.

Worked Example

Given f(x) = 2x + 1 and g(x) = x², find:

a) fg(x): f(g(x)) = f(x²) = 2(x²) + 1 = 2x² + 1

b) gf(x): g(f(x)) = g(2x + 1) = (2x + 1)² = 4x² + 4x + 1

Note: fg(x) ≠ gf(x)

Domain of fg(x): x must be in domain of g, AND g(x) must be in domain of f.
3

Inverse Functions

Only one-one functions have inverses. A function must pass the horizontal line test.

Finding the Inverse

  1. Write y = f(x)
  2. Rearrange to make x the subject
  3. Swap x and y
  4. Replace y with f⁻¹(x)
Worked Example

Find f⁻¹(x) given f(x) = (2x + 3)/(x − 1)

Step 1: y = (2x + 3)/(x − 1)

Step 2: y(x − 1) = 2x + 3 → yx − y = 2x + 3 → yx − 2x = y + 3 → x(y − 2) = y + 3

Step 3: x = (y + 3)/(y − 2)

Step 4: f⁻¹(x) = (x + 3)/(x − 2)

PropertyRelationship
Domain of f⁻¹= Range of f
Range of f⁻¹= Domain of f
Graph of f⁻¹Reflection of f in line y = x
f(f⁻¹(x))= x

Modulus Function

|x| = x if x ≥ 0
|x| = −x if x < 0

Graphs

TransformationEffect on Graph
y = |f(x)|Reflect negative parts above x-axis
y = f(|x|)Reflect right side to left (symmetric about y-axis)
Worked Example

Solve: |2x − 3| = 5

Case 1: 2x − 3 = 5 → 2x = 8 → x = 4

Case 2: 2x − 3 = −5 → 2x = −2 → x = −1

Answer: x = 4 or x = −1

Worked Example

Solve: |x − 2| < 3

−3 < x − 2 < 3

−1 < x < 5

⚠️ Common Mistakes to Avoid

  • Making sign errors when expanding brackets — especially with negative coefficients.
  • Forgetting to rationalise the denominator when simplifying surds.
  • Forgetting to give answers to the required degree of accuracy — check the question!
  • Confusing the formulae for circumference (2πr) and area (πr²) of a circle.
  • Using the wrong trigonometric ratio — SOH CAH TOA is essential for right-angled triangles.

✅ Key Points to Remember

  • Memorise all standard formulae — area, volume, trigonometry, circle theorems, etc.
  • Know how to construct angles (60°, 90°) and perpendicular bisectors using compasses and ruler.
  • Know your laws of indices and be able to apply them confidently.
  • Understand direct and inverse proportion and how to set up and solve proportion equations.
  • Be comfortable converting between fractions, decimals, and percentages.

Mathematical Reasoning: m2

Success in IGCSE Mathematics requires both procedural fluency and problem-solving flexibility. This topic builds on earlier foundations and connects to other areas of the syllabus.

Problem-Solving Strategies
  1. Read carefully: Identify what is given and what is required. Underline key information.
  2. Plan your approach: Decide which mathematical tools are needed before starting calculations.
  3. Show all working: Method marks are awarded for correct steps, even if the final answer is wrong.
  4. Check your answer: Substitute back, estimate, or verify using a different method.
Worked Example: Structured Approach

When approaching any multi-step problem:

Step 1: Define variables clearly.

Step 2: Write down relevant formulae or theorems.

Step 3: Substitute known values with units.

Step 4: Solve algebraically before calculating numerically.

Step 5: State the answer with appropriate accuracy and units.

In calculator papers, use your calculator efficiently but show the calculation you are performing. In non-calculator papers, look for simplifications, factorisations, and cancellations before multiplying large numbers.

Common Errors to Watch For

  • Sign errors when expanding brackets or collecting like terms
  • Forgetting to flip inequality signs when multiplying/dividing by negatives
  • Using the wrong trigonometric ratio — always identify opposite, adjacent, hypotenuse first
  • Incorrect unit conversions — write the conversion factor explicitly
  • Rounding too early in multi-step calculations — keep exact values until the final step

Worked Example 1: Solving Quadratic Equations

Problem

Solve 2x² − 7x + 3 = 0, giving your answers to 2 decimal places.

Solution

Using the quadratic formula: x = [7 ± √(49 − 24)] / 4 = [7 ± √25] / 4

x = (7 + 5) / 4 = 12/4 = 3.00

x = (7 − 5) / 4 = 2/4 = 0.50

Worked Example 2: Bearings and Trigonometry

Problem

A ship sails 15 km on a bearing of 060°, then 20 km on a bearing of 150°. How far is the ship from its starting point?

Solution

The angle between the two paths = 150° − 60° = 90°

Using Pythagoras: distance = √(15² + 20²) = √(225 + 400) = √625 = 25 km

Worked Example 3: Compound Interest

Problem

$5000 is invested at 4% per annum compound interest. Calculate the value after 5 years.

Solution

Amount = 5000 × (1.04)⁵ = 5000 × 1.21665 = $6083.26

Practice Questions

Question 1

The sum of the first n terms of an arithmetic progression is given by Sₙ = n(3n + 1). Find the 10th term.

Answer: 58

Question 2

Solve the simultaneous equations: 3x + 2y = 13 and 2x − y = 4.

Answer: x = 3, y = 2

Question 3

A map has a scale of 1 : 50,000. A rectangular field measures 4 cm by 6 cm on the map. Calculate the actual area of the field in km².

Answer: 6 km²

🎯 Examination Tips

  • In probability questions, write probabilities as fractions, decimals, or percentages — not ratios.
  • For "show that" questions, work towards the given answer, not from it.
  • Check the number of marks available — this indicates the expected depth of working.
  • Leave time to review calculations, especially those involving negative numbers or fractions.
  • Use a sharp pencil and ruler for all diagrams and graphs.

📝 Quick Summary

  • fg(x) = f(g(x)) — apply g first, then f
  • Inverse: write y = f(x), rearrange for x, swap x and y
  • Domain of f⁻¹ = Range of f; Range of f⁻¹ = Domain of f
  • |x| = x for x ≥ 0; |x| = −x for x < 0
  • Only one-one functions have inverses

💡 Exam Tips

  • Always check if a function is one-one before finding its inverse
  • For composite functions, work from the inside out
  • When solving |f(x)| = a, always consider ±a
  • Draw the line y = x to check inverse reflections
