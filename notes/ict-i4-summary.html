Software, OS & Applications

Topic i4 — Revision Summary

📝 Last-Minute Summary

  • OS functions: memory, processor, file, device management + security + UI.
  • Scheduling: FCFS, SJF, Round Robin, Priority. Round Robin uses time quantum.
  • Memory management: paging (fixed frames/pages), segmentation (variable), virtual memory (disk extension).
  • Translation: Compiler (whole program → machine code), Interpreter (line-by-line), Assembler (assembly → machine code), JIT (runtime compilation).
  • File systems: FAT32 (old, limited), NTFS (Windows, journaling), ext4 (Linux), APFS (macOS SSD).
  • Licensing: Proprietary, Open Source, Freeware, Shareware. FOSS = free + open.
  • SDLC: Waterfall (linear), Agile/Scrum (iterative sprints), Spiral (risk-driven).
  • Testing: White-box (code visible) vs Black-box (interface only); Unit → Integration → System → Acceptance.
  • Virtualisation: VMs (full OS emulation) vs Containers (shared kernel, lightweight).
  • Exam tip: For OS scheduling questions, always explain the impact on waiting time and turnaround time.

🔑 Key Terms

  • OS, GUI, CLI, Driver, Buffer, Spool, Defragmentation, Journaling
  • FCFS, SJF, Round Robin, Time quantum, Page fault, Thrashing
  • Compiler, Interpreter, Assembler, JIT, Bytecode
  • Proprietary, Open Source, FOSS, GPL, MIT
  • Waterfall, Agile, Scrum, Sprint, Backlog
  • White-box, Black-box, Unit test, Integration test, Beta test
  • VM, Hypervisor, Container, Docker, Kubernetes

🎯 Exam Tips

  • Always distinguish system software from application software with examples.
  • For scheduling, explain starvation risk and context-switch overhead.
  • When asked about file systems, mention journaling for reliability.
  • In Agile vs Waterfall, mention adaptability to changing requirements.
