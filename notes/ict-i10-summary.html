Emerging Technologies & AI

Topic i10 — Revision Summary

📝 Last-Minute Summary

  • AI types: Narrow (current), General (future), Superintelligence (speculative).
  • Machine Learning: Supervised (labelled data), Unsupervised (patterns), Reinforcement (rewards).
  • Neural Networks: Input → Hidden → Output layers. Train via forward pass, loss calculation, backpropagation, gradient descent.
  • Overfitting = memorization; prevent with regularization, dropout, more data.
  • NLP: Tokenization, word embeddings, Transformers, LLMs (GPT, Claude). Hallucination = key risk.
  • Computer Vision: CNNs for images; object detection (YOLO), segmentation, GANs/diffusion for generation.
  • IoT: Connected sensors in homes, cities, industry, wearables. Security is critical concern.
  • Blockchain: Distributed ledger, consensus (PoW/PoS), smart contracts, NFTs, DeFi.
  • Ethical AI: Bias mitigation, explainability (XAI), governance (EU AI Act), autonomous weapons debate.
  • Evaluation: Use STEEPLE framework for comprehensive technology assessment.
  • Exam tip: Link emerging tech to real examples and current events. Mention specific companies/products (AlphaGo, ChatGPT, Waymo) for credibility.

🔑 Key Terms

  • AI, Narrow AI, AGI, Machine Learning, Supervised, Unsupervised, Reinforcement
  • Neural Network, Deep Learning, CNN, RNN, Transformer, LLM, GPT, Backpropagation
  • Overfitting, Underfitting, Regularization, Dropout, Gradient descent, Learning rate
  • IoT, Smart home, Wearable, IIoT, Edge computing
  • Blockchain, Proof of Work, Proof of Stake, Smart contract, NFT, DeFi, Cryptocurrency
  • Bias, Explainability, XAI, SHAP, LIME, Federated learning, Transfer learning, AutoML
  • Neuromorphic, Quantum ML, BCI, CRISPR, STEEPLE

🎯 Exam Tips

  • Use current, specific examples — generic answers score lower.
  • For AI questions, distinguish between training phase and inference phase.
  • When discussing ethics, always propose solutions/mitigation, not just problems.
  • For emerging tech evaluation, apply STEEPLE systematically with examples for each dimension.
  • Mention limitations and hype vs reality — balanced analysis scores higher.
