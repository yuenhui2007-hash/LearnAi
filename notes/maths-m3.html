Coordinate Geometry

9709 · 0580

Detailed Notes

1. Straight Line

Gradient m = (y₂-y₁)/(x₂-x₁)
y = mx + c
y - y₁ = m(x - x₁)
ax + by + c = 0

2. Distance and Midpoint

Distance = √((x₂-x₁)² + (y₂-y₁)²)
Midpoint = ((x₁+x₂)/2, (y₁+y₂)/2)

3. Circle

(x-a)² + (y-b)² = r²

Centre (a,b), radius r.

Last-Minute Summary

  • Gradient = Δy/Δx
  • y = mx + c; y-y₁ = m(x-x₁)
  • Distance formula; Midpoint formula
  • Circle: (x-a)² + (y-b)² = r²

📐 Worked Example

Question: Differentiate y = 3x⁴ + 2x² − 5x + 7

Solution:
dy/dx = 3(4x³) + 2(2x) − 5(1) + 0
dy/dx = 12x³ + 4x − 5
Answer: dy/dx = 12x³ + 4x − 5
Forgetting the +c (constant of integration) for indefinite integrals. You'll lose a mark!
The chain rule: if y = f(g(x)), then dy/dx = f'(g(x)) × g'(x). Use for functions inside functions.

⚡ Quick Recall

  • d/dx(xⁿ) = nxⁿ⁻¹
  • ∫xⁿ dx = xⁿ⁺¹/(n+1) + c
  • Chain rule: dy/dx = dy/du × du/dx
  • Stationary points: dy/dx = 0; d²y/dx² > 0 = min
